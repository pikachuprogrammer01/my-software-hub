# TableFlow — 网页表格采集与导出

> Chrome / Edge 浏览器扩展（Manifest V3），从网页表格中提取、预览、去重并导出数据。
> 以浮动操作面板形态运行（Shadow DOM 隔离），支持原生表格和主流 UI 框架表格。

**一句话定位**：页面上已经显示出来的表格，TableFlow 就能采集——它读的是浏览器渲染出来的成品页面，不去猜网站后台的数据。

**它是什么**：轻量级网页表格采集工具，而不只是"表格导出器"。采集、预览、导出默认都在本地完成；匿名错误诊断可在设置中关闭。适合需要频繁从网页取结构化数据、又不想上手爬虫框架的人。

## 三个最能省时间的能力

- **自动翻页采集 + 断线续采**：识别「下一页」按钮和"只有 1 2 3 … N"的页码分页器两类入口，识别不中可以手动拾取；每页数据实时落盘，刷新或重开面板可继续未完成任务。
- **模板系统**：把列配置存成模板，下次进同域名/同 URL 页面自动匹配、一键套用。
- **政务与内嵌页面**：跨域 iframe 白名单默认放行 `.gov.cn`、`.mil.cn`、`.gov`，公示表、处罚表、招投标表这类"嵌在别的窗口里的表"无需任何设置即可采集。
