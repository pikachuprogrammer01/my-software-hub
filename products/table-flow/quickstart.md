# 快速上手

> 来源：`table-flow/README.md` 快速上手 + `UsageGuideContent.vue`（面板内嵌文案基准）+ `docs/USAGE_GUIDE.md` 快速上手。

## 面板里的四步

| 步骤 | 名称 | 做什么 |
|------|------|--------|
| ① | 打开浮动面板 | 在含表格的页面点工具栏 TableFlow 图标 |
| ② | 选择表格与列 | 在列表里点目标表格（页面同步高亮），勾选要导出的列、拖拽排序 |
| ③ | 配置采集方式 | 仅当前页 / 自动翻页（设最大页数、翻页入口） |
| ④ | 预览并导出 | 核对数据、去重，选格式导出 |

## 一次完整导出流程

1. **打开插件**：在包含表格的页面，点击浏览器工具栏的 TableFlow 图标
2. **选择表格**：在浮动面板的表格列表中点击目标表格，对应表格在页面高亮
3. **配置列**：勾选需要导出的列，可拖拽调整顺序；需要时添加识别列
4. **选择采集模式**
   - 仅当前页：只采集当前页面数据
   - 自动翻页：设置最大页数，自动翻页采集多页
5. **预览数据**：确认数据是否正确，可检测重复并去重
6. **导出**：选择 Excel / CSV / JSON / 剪贴板 格式导出

**步骤条可点跳转**：顶部四步可随时点击回退或前进（未选表格时不能直接进列配置）。

## 模板自动匹配

下次访问同域名页面时，面板顶部会显示匹配到的模板，点击即可一键应用之前的列配置。模板管理页里，匹配当前页面的模板会自动高亮并置顶。

## 使用提示

- 表格没出现在列表里：先点「刷新」重扫；延迟渲染的框架页面等渲染完成后再扫。
- 翻页没自动翻：用「翻页模式 → 手动选择」，点一下页面上的下一页按钮或页码数字。
- 采集过程别滚页面：采集时会盖半透明遮罩并锁定滚动，25 秒无活动会自动暂停，已采数据不丢。
- 长数字（手机号/身份证）：用 Excel 或 JSON 导出不会变科学计数法；用 CSV 则在 Excel 里把该列设为文本。
- 想复用配置：列配好后「保存为模板」，按域名或完整 URL 匹配。

详细操作说明见[完整使用手册](/table-flow/usage-guide)。
