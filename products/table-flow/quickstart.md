# 快速上手

先从当前页导出一份小表熟悉流程，再尝试翻页采集。单页采集免费；免费翻页任务确认开始即消耗1次额度，失败、零结果、结束或清理不退还；同任务继续、切换和重复输出不再扣费。采集与结果处理都在浏览器本地完成。

## 先认识操作入口

1. 在浏览器打开有表格的业务网页，等表格数据出现。
2. 点击浏览器工具栏的 TableFlow 扩展图标，扫描网页。页面上已有悬浮图标时，点击悬浮图标展开面板；工具栏没有显示扩展时可先把它固定。
3. 确认面板顶部处于「采集网页数据」。四步依次是选择表格、配置列、预览数据、导出。
4. 要把 Excel 写入网站，切换顶部「Excel 填充网页」，按本文后面的[填充步骤](#excel-填充网页入门)操作。

| 入口 | 用途 |
|---|---|
| 表格列表「刷新」 | 重新扫描页面，选中后高亮对应表格 |
| 配置列「仅当前页」 | 采当前页面；支持的虚拟表会在本页自动补滚 |
| 配置列「翻页采集 → 自动翻页」 | 设置最大采集页数和入口后连续采集 |
| 配置列底部「手动翻页采集」 | 先采本页，再等你点击网页或面板「下一页」 |
| 状态栏「暂停 / 继续 / 结束采集」 | 暂停、接续同一任务，或确认结束并保留结果 |
| 预览底部「翻页模式」 | 运行、暂停或失败时从同一行切换自动 / 手动，中央弹窗确认后直接执行 |
| 预览「显示全部 … 行」 | 展开已保存结果，不触发额外扣费 |
| 面板头部「统计」 | 对选中表格的数值列做统计，免费使用 |
| 状态栏「任务操作」 | 暂停后选择「清理本次任务数据…」 |
| 「保留的采集任务」 | 「恢复结果」再次输出，或「清理此任务数据…」删除历史任务 |

## 第一次导出：先采当前页

以网页上有 20 行订单、包含“订单号、客户、金额”三列为例：

1. 在表格列表中点这张表，确认网页高亮的是订单表。
2. 进入列配置，勾选这三列；不需要的操作按钮列可以取消，拖拽调整导出顺序。
3. 选择「仅当前页」，点击采集并等待本页完成。遇到虚拟滚动表时，让插件完成滚动再操作网页。
4. 在预览中核对列名、订单号和总行数。默认先看前 10 行，可点「显示全部 … 行」展开；单页采集不消耗翻页额度。
5. 点「确认导出」进入导出步骤，选择 Excel，按需要开启「保留网页样式」或文本格式，填写文件名后导出。
6. 打开文件核对：应有这 20 行订单；长订单号保持文本。需要 CSV、JSON、Markdown 或剪贴板时可切换格式重新输出。

如果页面声明的行数比结果多，先看[行数不足的排查](/table-flow/troubleshoot#表格识别出来了-但只有一部分行)，再决定是否重采。

## 自动翻页：指定本次采集范围

以网站每页 20 行、当前停在第 3 页、想采到第 6 页为例：

1. 选中表格并配置列，选择「翻页采集」，执行方式选「自动翻页」。
2. 把「最大采集页数」设为 `4`。首次自动任务的这个数字**包含起始页**，因此采集第 3、4、5、6 页。默认值为 <Fact product="table-flow" id="limits.autoPaging.maxPages" />，可按任务调整。
3. 翻页方式先选「自动识别」。识别不准确时改为「手动选择」→「去页面选择」，在网页点下一页按钮或数字页码，按提示确认入口。
4. 核对开始确认框中的目标表、范围和方式，再确认开始。免费任务此时扣1次，扣费结果确认后才读页；开始后不退还。
5. 等待采集，状态栏显示实际页数与行数。达到设定页数、网站末页或没有数据时立即暂停，留在结果预览并解除操作阻塞。
6. 按下文[完整预览与输出](#首次完整预览、导出或复制)选择格式；若四页各20行且没有额外去重，应得到80行。需要继续已经完成的自动段时，先输入新的后续次数 `N`。

「手动选择」只负责挑选自动翻页入口。选好入口后仍由插件连续翻页；想由自己控制每一页，应使用下一节的手动翻页采集。

## 手动翻页：按自己的节奏接续

1. 在目标表格的列配置底部点「手动翻页采集」，确认开始。也可在「翻页采集」的执行方式里选「手动翻页采集」。
2. 等起始页采集、保存完成，看到“请在网页上翻页，或点面板下一页”的提示。
3. 点击**这张表所属**的网页下一页，或者点面板「下一页」前进一次。状态栏会按实际进度显示权限核验、翻页、等待网页加载核对新页、读取和保存；等本页保存完成、恢复「请翻页」后再前进。
4. 正常“等待手动翻页”没有固定倒计时，你可以核对业务数据；明确暂停后继续仍用原任务，不重复扣费。联网确认失败按提示恢复。
5. 采够后可暂停并输出；不再追加数据时点「结束采集」并确认，保留已确认结果，已扣次数不退还。

例如采到第 4 页后需要检查订单，你可以保持手动等待；需要关闭面板离开时，按[暂停与恢复](#暂停、关闭或采完后稍后交付)处理。手动实际读页与自动采集共用提示和动画；本页保存后解除遮罩及滚动锁，静态等你翻页，不能把滚动、排序或旧记录重新出现当作已翻到新页。

## 在自动与手动之间切换

1. 在预览底部同一行「翻页模式」点自动或手动。运行、暂停和翻页失败时都可切换，无需先结束或返回列配置。
2. 网页中央立即打开确认框；手动转自动时，在「接下来自动翻几页？」输入框填写后续页数。如果上一轮点击或读取还在进行，系统停止后续导航，先核对实际落页并保存。核对完成前确认按钮不可用，仍可取消。
3. **手动转自动**：填写 `N`，点「切换并开始自动翻页」，确认成功后直接执行，无需再点继续。`N` 不含已完成页；例如已保存网站第6页，填 `3`，接着采第7～9页。
4. **自动转手动**：点「切换为手动翻页」直接进入手动等待，不自行点击网页。看到「已采集 N 条 · 请翻页」后，操作网页或点面板「下一页」；仍可点「暂停」或「结束采集」。明确暂停后点「继续」接续原任务。
5. **取消或 Escape**：保留原模式和结果，保持暂停。要继续原模式再点「继续」；未执行的新模式不会显示为当前模式。
6. **自动段完成**：立即暂停并保留预览。继续未完成段沿用剩余次数；继续已经完成的段先填写新的 `N`，确认后执行下一段。

切换保留原任务与已确认页，不再次扣费。交接核对失败时保留结果和本页断点，先核对页面或重新选择分页器。变更网站、表格或数据来源应新建任务。

## 首次完整预览、导出或复制

新免费翻页任务在确认开始时已扣1次，预览不设首次交付样例闸门。

1. 在预览核对已保存页数、行数和列名；点「显示全部 … 行」展开结果，「显示全部 / 收起」只调整显示范围。
2. 输出前暂停并保存当前进度。当前页未完成时先继续完成或按提示处理草稿，不把未确认草稿当成完整结果。
3. 到导出步骤选择 Excel、CSV、JSON、Markdown 或剪贴板并输出，不另作一次扣费确认。
4. 文件生成失败或取消保存，修正后对同一任务重试即可；换格式、再次复制和重复查看都不再扣费。
5. 还要采更多页时可以继续尚未结束的原任务；确认「结束采集」后保留结果，之后再采须新建任务并再次扣费。

如果开始时提示扣费结果待确认，保留任务并重试原开始操作；系统先核对原请求，无法确认时暂停。即使采集失败或零结果，已确认扣费也不退还。

## 暂停、关闭或采完后稍后交付

| 你看到的状态 | 额度和数据怎么处理 | 下一步 |
|---|---|---|
| 等待手动翻页 | 正常等待无固定时限，开始时已扣1次 | 需要时翻下一页，联网确认异常按提示恢复 |
| 已暂停、关闭面板，或自动段已完成 | 保留已确认数据，已扣次数不退还 | 恢复原任务；未完成自动段保留剩余次数，已完成段先输入新 `N` |
| 任务已结束 | 结果保留，同一任务重复输出不再扣费 | 恢复输出；要采更多页则新建任务 |
| 升级前的旧任务 | 仅按原协议兼容核对预留或未确认结算 | 保留原任务和原请求，按该任务提示恢复 |

暂停、查询和重新打开面板都不改变已经扣费的事实，也不为新任务生成退款或再次扣费。断网时保留已确认结果，联网后沿原任务恢复。

## 跨标签页或浏览器重启后恢复

1. 在同一浏览器配置中打开可使用 TableFlow 的网页，展开面板，找到「保留的采集任务」。
2. 对照任务来源、行数和状态，点该任务「恢复结果」。
3. **只需输出**：原业务标签页可以已关闭；恢复结果后直接预览或导出，已确认开始扣费的任务不再扣费。升级前旧任务若有待确认结算，沿原请求提示核对。
4. **还要继续采集**：回到任务绑定的原标签，核对同一来源、表格与实际落页再继续。原标签关闭或重启后标签身份变化时，先输出原结果，再新建任务采后续页。
5. 不再需要某个历史任务时，点对应条目「清理此任务数据…」；当前任务先暂停，在底部「任务操作」选「清理本次任务数据…」。核对确认框的来源、行数及无法恢复提示，再点「清理本地数据」。断网也可清理，已扣次数不退还；旧任务的账务兼容由系统处理。

任务保存在扩展本地存储中，跨标签和重启恢复需要保留该浏览器配置与扩展数据；清理后无法恢复或继续该任务，请先导出。采集运行中、导出中或任务操作尚未完成时清理入口暂不可用，按提示等待；仅在显示「本地清理尚未完成」时点「重试本地清理」。

## 翻页失败时保留已完成部分

1. 先看提示的最后确认页与已确认行数，核对网页当前页。不要连续点击下一页，以免跳过尚未确认的页面。
2. 自动翻页失败会暂停并解除操作阻塞。可在同一行「翻页模式」改为手动；入口失效时，暂停后回列配置重新拾取分页器，再核对落页接续原任务。
3. 手动页身份不明时，按提示核对来源、同一张表与实际落页，再从原任务继续；需要切换方式时使用同一模式行的中央确认框。
4. 网站已无法继续时，结束采集，确认只交付已完成页。若有当前页草稿，按提示明确舍弃；例如前 3 页已确认、第 4 页读取失败，可交付前 3 页。
5. 已扣次数不因失败退还，同任务续采和输出不再扣费。文件保存失败时重试输出；开始扣费响应丢失时，保留原任务核对原请求。

恢复输出不受原标签是否存在影响。继续同一任务采集需要保有原绑定标签，并核对来源、表格和页位置；原标签关闭或重启后标签身份变化时，先输出保留结果，再开启新任务采后续页。

## Excel 填充网页入门

这一流程把 Excel 行写入目标网站。单页批量填写免费；**免费翻页填充在开始时扣一次**，与网页采集共享额度，使用原填充计费规则。

1. 切换顶部「Excel 填充网页」，导入 `.xlsx`、`.xls` 或 `.xlsm`，选择工作表。
2. 填写「开始列、结束列、开始行、结束行、表头行」。例如文件 A1:C1 是“姓名、部门、金额”，A2:C11 是 10 条数据，开始列 A、结束列 C、开始行 2、结束行 11、表头行 1；无表头时取消对应选项并核对数据起始行。
3. 进入「设置填充行列」，用「列选择 / 行选择 / 逐个字段」在网页点可写控件。选择网页目标后停止拾取，进入下一步。
4. 在「检查映射」核对 Excel 字段、网页控件、当前值和可写状态；先检查一条记录的对应关系，再运行整批。
5. 开始批量填充，观察每条成功或暂停原因。手动翻页时先填当前页；本页完成后在网页或面板翻一页，再点击底部「确认填充本页」。确认前不写新页，同一批次不重复扣费。单页的普通表格填写只写值；网站自行校验和保存的结果需在网站确认。
6. 要切换为连续翻页时，输入接下来要自动翻的页数。网页已在下一页时，先点「确认填充本页」，当前页不计入后续次数。自动入口失效可转手动。修改「待填数据」后点「应用草稿」生效。

下拉匹配、部分写入和保存未知等问题见[填充排查](/table-flow/troubleshoot#excel-填充网页)。逐条新增表单的保存与下一条动作需单独绑定，详见[完整使用手册](/table-flow/usage-guide)。

## 新界面里从哪里打开设置

点击浮动面板「升级 Pro」或「Pro」打开独立管理页，默认是「账户」。顶部「订阅」用于购买和激活，「设置」用于调整偏好；免费用户也能打开。宽窗口先选左侧分类，再选页内标签；窄窗口分类在内容上方。顶部搜索支持关键词，`⌘K` / `Ctrl+K` 聚焦搜索。
