## 采集

| 自动 / 手动切换 | 运行、暂停与失败时在同一行操作；在「翻页模式」选择后，网页中央确认即执行；转自动填写后续次数，核对实际落页。取消保留原模式并暂停；未完成自动段保留剩余次数，已完成段继续时先输入新 N |

| 跨域 iframe 采集 | 白名单域名内的嵌套表格可扫描 / 读取 / 翻页 / 高亮，翻页入口也能在帧内手动点选；帧内表不参与合并 |

## 导出

| 格式 | 说明 |
|------|------|
| Excel (.xlsx) | 手机号、身份证等超长数字强制文本格式，不会变成科学计数法；多级表头还原；可开启「保留网页样式」导出带颜色边框的 Excel |
| CSV | UTF-8 BOM（Excel 打开中文不乱码）；逗号引号正确转义；对 `=`、`+`、`@` 开头的字段加防护前缀，避免公式注入 |
| JSON | 二维数组 / 对象数组两种结构可切换；超长数字保持文本 |
| Markdown | GFM 管道表格；该语法没有合并单元格概念，合并区只保留左上角值、多级表头压平为「上级 > 子级」——要保真合并形态请用 Excel |
| 剪贴板 | 同时写入富文本与纯文本，可直接粘进表格软件 |
| 脚注标记剥离 | 「移除脚注标记」默认开启：导出与预览会去掉**单元格末尾**的 `[1]`、`[a]`、①、※ 这类标记；方括号年份编号（`[2024]`）、两位字母缩写（`[OK]`）等真内容原样保留；关闭后输出与原始采集逐字节一致。另有「移除行内脚注标记」（默认关闭）：开启后 `依据[1] 见附注` 这类行内标记也去掉，只处理两侧是空白或标点的标记；`<sup>` 仍按正文处理 |
| 文件名 | 默认 `YYYY-MM-DD_HHmm_TableFlow.{ext}`（本地时区）；「导出前可修改文件名」默认开启，可直接改基本名，扩展名由系统按所选格式自动补齐，不合规只报错不改写 |

## 批量当前页采集导出（Pro）

勾选多张表一次采完再导出，不必逐张走四步。每张表串行采集、状态与行数实时可见，单表失败不影响其余表。交付方式二选一：**一个文件多 Sheet**（Excel / JSON / Markdown）或**压缩包每表一个文件**（Excel / CSV / JSON / Markdown，包内附 `_采集完整性.txt` 逐表核对）。设置页的导出设置（脚注剥离、强制文本格式、文件名编辑）对批量导出同样生效；批量导出保留单元格合并结构，不保留字体颜色与背景色。

## Excel 填充网页

与采集方向相反的第二条工作流：把本地 Excel 的每一行，按顺序**填进网页表单**，适合 ERP 单据起草、订单/库存录入这类重复录入。既有表格模式只写值；逐条新增表单可人工保存，或在绑定保存动作、成功凭据并允许本批后自动保存。**单页批量填写免费**；翻页与采集共用免费机会，**网页填充翻页仍在开始时扣费**；填充模板是 Pro。

四步：**选择表格 → 设置填充行列 → 检查映射 → 批量填充**，步骤条与采集模式一致，可点回前一步查看和修改。

- **第一步 选择表格**：导入 `.xlsx`/`.xls`/`.xlsm`，范围用五项输入——**开始列、结束列、开始行、结束行、表头行**。默认包含表头（取已用范围第一行），无表头时取消勾选并重新核对开始行；非法或倒序范围会提示并禁用下一步。可跳过隐藏行列，水平合并单元格按**一个逻辑列**处理，只取合并区左上角的值。
- **第二步 设置填充行列**：三个方式按钮都带可见的「行 / 列 / 字段」短标签。**列选择**依次点击可填位置连续选多列；**行选择**点一行里任意可填位置即选中该行全部可填字段；**逐个字段**每次点一个，**可跨行、跨表挑选**（只提醒不拦截，填充前才校验）。
  - **同一列选多行会自动识别为「行 × 列」区域**——行是记录、列是字段，第 N 条 Excel 记录写第 N 行，不会串列；标题实时显示「已选 N 行 × M 列 · 共 K 个单元格」。区域填完即暂停，剩余记录可翻页继续或扩大选择。
  - **单击选择，再次单击取消**；**关闭浮动面板不会结束拾取**，收起期间继续点网页目标仍会被记录，重开即可看到。
- **第三步 检查映射**：双列展示「Excel 逻辑列 ↔ 网页目标」，每行源列下拉都可选 **「None（不填充）」**，没有可写控件的目标自动默认 None 并跳过。下方是**最多前 10 行 × 前 10 列的对照表**，每个已选目标并列显示 Excel 值与真实网页原值；源范围、隐藏行、映射与所选网页行顺序都参与对照。源范围或选择变化后需点刷新重读网页原值。停止说明会具体到行号与原因（如「第 3 条网页行的列数或合并结构与上一条不同」）。
- **第四步 批量填充**：点「开始批量填充」自动逐行写入，可暂停、继续或取消。映射为 None 的目标与空单元格一样不触碰网页控件。支持可写的文本/日期/数值 input、textarea、原生 select、简单 contenteditable、双态复选框与选项可验证的原生/ARIA 多选下拉。
  - **自动翻页**：与采集共用下一页按钮、页码序列识别、手动拾取与翻页验证；每个新翻页批次消耗一个共享机会，暂停继续不重复扣减。达到最大页数或无法确定下一页时暂停，并写明**剩余记录数**。
  - **填完后再开始新一轮**：上一轮填完后重选目标或改映射会自动回到 Excel 第 1 行，避免对照表变成空表。
- **类型化写入**：Excel 日期写进日期控件就是 `2026-10-16`，分组金额写进数字控件就是 `1200.50`；有歧义的文本不猜。
- **下拉严格匹配**：去两端空白、区分大小写的**唯一**启用项命中才算成功，禁用项不参与；集合预检默认开启，不一致时按设置询问、跳过字段或停止。
- **失败不推进**：预检发现不可写控件或待确认项时整条记录零写入；运行中按字段写入并回读，遇拒绝立即停止。空单元格跳过不触碰网页控件。
- **撤销上次填充**：可在同一会话内恢复本次写入前的值（含下拉拍扁），前提是文档、控件身份与写后值都未变。
- **填充模板（Pro）**：指定表头行后可保存、重命名、删除模板，只存范围、映射与目标定位，不存数据行和下拉选项。恢复时按 Sheet、字段数、表头顺序与网页区域匹配；恢复后仍进检查映射，**不会自动填充**。免费用户在成功填完一行后会看到带锁的升级说明，填充前不显示。
- **本地解析、不上传原文件**：不执行 VBA/宏/公式，不新增权限，不把工作簿长期写入扩展存储。写入事件和获准保存会把字段交给目标网站，其校验、自动保存或网络请求可能执行。
- 适用边界见[适用范围与边界](/table-flow/scope)；完整操作见[使用指南](/table-flow/usage-guide)

### 逐条新增表单与当前记录试填

「逐条新增表单」把一条 Excel 记录填入一张新建表单，支持字段来源、明确选择的固定值、标签转换、条件依赖和双态复选框；表单模式仍不支持多选下拉。先试填，再逐条人工核对保存，或绑定可验证的成功结果并允许本批自动保存。保存结果未知时暂停核对，不能直接重试提交。表单模板仅存本机，固定值默认不保存，本批许可不随模板保存。

「当前表单只试填」现阶段仅对手动打开的当前记录试填一个文本字段，须绑定页面公开可见的患者与就诊标识；不自动保存、不切换记录、不批量推进。实际业务站点仍需单独验证。完整操作见[使用指南](/table-flow/usage-guide)。

## 界面与交互

- **四步流程**：① 选择表格 → ② 配置列 → ③ 预览与去重 → ④ 导出；顶部步骤条可点击跳转（受守卫约束，未选表不能进列配置）
- **模式切换**：面板头部可在「采集网页数据 / Excel 填充网页」之间切换，两条工作流数据互不干扰
- **浮动面板**：Shadow DOM 隔离、固定最高层、不挤压页面内容；ESC 可关；采到表格后点悬浮图标可收起面板，图标右上角出现「×」
- **FAB**：48px 浮动按钮，可拖拽，位置持久化，可在设置里重置。扫描到候选表后即可见「×」（列配置阶段也在）；点「×」默认只隐藏图标、不清数据（可在设置里改为隐藏时清除，或隐藏后静默扫一次）。图标隐藏后点浏览器工具栏的扩展图标即可恢复并直接打开面板，刷新页面也会恢复；而图标还在、只是面板收起时，点扩展图标只重扫一次、不替你开面板（面板开合始终由悬浮图标负责）
- **设置开关**：所有「是 / 否」选项统一为滑块（在右显示「开」为开启），键盘 Tab 选中后按空格或回车同样可切换
- **欢迎页**：安装后自动打开——上手入口、教程与场景边界、隐私政策链接集中一处
- **状态与提示**：底部状态栏实时显示已采集条数；Toast 覆盖暂停/继续/结束采集、自动段完成、导出成功、操作失败
- **明确告知不支持的页面**：`chrome://`、扩展商店等浏览器禁止注入的页面，面板会直接说明原因

## 手动翻页

直接点「配置列」底部独立的「手动翻页采集」并确认，先读本页再等你点网页或面板「下一页」，无遮罩、倒计时或最大页数。「手动选择」只是连续模式拾取入口。手动模式复用原生表、框架表、列表、ARIA、已适配的自定义网格、合并表及可定位 iframe 的读取能力；虚拟页内自动补滚，不扩大 AG Grid/MUI/SlickGrid 的渲染窗口能力。

新页须有可核验动作和页身份/新记录；滚动本身不算换页。无总量短末页依末页证据封页；真实页标允许相邻页保留重复业务记录。列结构变化、回退或身份不明暂停保留确认数据。填充可手动翻页沿同一批次/源游标接续，待填数据编辑可应用或取消，采集支持不等于填充可写。

## 交付、恢复与清理

新免费翻页任务确认开始扣1次；失败、零结果、结束和清理不退款。同任务暂停后继续、切换执行方式、反复完整预览、文件导出与复制不再扣费。实际次数以账户为准，不保证固定赠送数量。

输出前暂停并保存进度，当前页未完成时先继续完成或按提示处理草稿。输出不会将尚未结束的任务自动变成不能续采的结果；明确结束后才定稿，追加页面需新建任务。开始或查询超时沿原任务、原请求核对，扣费未确认时不放行采集。

当前任务先暂停，在底部「任务操作」选择「清理本次任务数据…」；历史任务在「保留的采集任务」点对应条目「清理此任务数据…」。核对来源和行数后点「清理本地数据」，清理后不能恢复或继续此任务。断网时也可删除本地原文，已扣次数不退还；请先导出要保留的数据。升级前旧任务的预留与未确认结算只作兼容核对；已删除的数据不会重新出现。连续操作见[快速上手](/table-flow/quickstart)。

## 账户、赠额与离线 Pro

账户显示实际可用与已用次数，赠额按钮只复核原未到账机会；额外额度和续费由管理员后台处理。Pro 保留订阅页已有的微信 / 支付宝人工付款、发送设备码和激活码激活路径，不再提供重复购买续费卡片。离线激活属于付费 Pro 服务，建议先在线试用目标网页。步骤见[免费版与 Pro](/table-flow/pricing)。

## 调试时解除 debugger

默认不向网页预装计时器干预。只有在调试菜单点「解除 debugger」并确认后，才跳过当前 frame 未来新增的纯 debugger 计时回调；普通业务计时器、混合业务函数和字符串，以及无法安全识别的回调保持原样，仍可能触发 debugger。已有计时器不受安全步骤影响，破坏性清扫需要另行明确选择。旧页面上的旧补丁需刷新移除，关闭控制台不能撤销。详见[排查手册](/table-flow/troubleshoot#解除-debugger-与页面计时器)。
