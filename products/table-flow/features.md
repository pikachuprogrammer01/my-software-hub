# 功能全景

> 来源：`table-flow/README.md` 功能特性 + `docs/SCOPE_AND_FEATURES.md` §四 功能清单（已删去代码路径与内部阈值表述）。
> 免费版 / Pro 分级见[免费版与 Pro](/table-flow/pricing)；"能不能采到"见[适用范围与边界](/table-flow/scope)。

## 采集

| 功能 | 你能得到什么 |
|------|--------------|
| 表格扫描 | 自动列出页面上可采集的表格，过滤排版用的空表；选中即在页面高亮 |
| 当前页采集 | 直接读取当前已渲染的一屏数据 |
| 自动翻页采集 | 三级识别翻页入口：手动拾取 → 自动识别「下一页/›/next」文字与框架类名 → 表格附近可点击按钮兜底；都不命中且允许时改用「页码序列分页器」。默认最多 <Fact product="table-flow" id="limits.autoPaging.maxPages" />，**自本次起始页起算** |
| 页码序列翻页 | 只有 1 2 3 … N、没有下一页按钮的页面也能自动翻页；点击后强制校验页码确实 +1，防止静默跳页漏采；失败自动自愈，全落空则软暂停并保留已采数据 |
| 加载更多 / 无限滚动 | 「加载更多」按钮与滚动触底加载按**新增行数**推进，旧行不会重复计入；按钮消失、触底零新增或连续点击无新行时按数据末尾自动停止，终止原因写入采集结果；设置里可整体关闭这类入口 |
| 手动拾取翻页入口 | 进入点选模式，悬停高亮候选、点击确认；拾到数字页码时会问你要"按页码序列采集"还是"固定按钮" |
| 列表型表格（ul/li） | 政府公告、新闻聚合这类 `ul`/`ol` 列表按表格采集：每个列表项一行、行内重复子结构为列；导航、菜单、面包屑、分页器自动排除；列名可按站点自定义，识别严格度分严格/标准/宽松三档（只采当前页） |
| 单元格内表单控件 | 输入框 / 下拉 / 文本域按**你当前看到的值**采集（含只读、禁用态与脚本改写后的实时值）；复选/单选采勾选态，文件框采文件名，多选下拉只导出已勾选项；密码固定脱敏 |
| 虚拟滚动表格 | 证据充分时自动滚到底、逐屏抓取并按行身份去重，拿到全量行——**不需要开启自动翻页** |
| 实时缓存与断线续采 | 每页采完立即落盘；重开面板可选择「继续采集 / 直接导出 / 丢弃重启」；大表支持行级断点续采；**已完成的结果同样进横幅**，页面被站点跳走后同标签页重开即可直接导出 |
| 暂停 / 继续 / 终止 | 随时可停；暂停、终止、关面板都不丢已确认数据 |
| 采集遮罩 | 采集期间覆盖页面并锁定滚动，避免误操作打断；25 秒无活动自动暂停 |
| 跨域 iframe 采集 | 白名单域名内的嵌套表格可扫描 / 读取 / 翻页 / 高亮 |
| 采集调试控制台 | 面向排障：日志、虚拟检测、DOM 快照、合并对比、采集追踪、诊断、网络七页签取证（默认关闭） |

## 整理数据

| 功能 | 你能得到什么 |
|------|--------------|
| 列配置 | 勾选/反选、全选、拖拽排序（不支持拖拽的浏览器给上移/下移按钮）；至少保留一列 |
| 识别列（数据验证） | 把正则规则挂到已有列，预览时告诉你这列**全部通过 / 全部失败 / 部分通过**（附失败样例）。内置 97 条规则、12 个分类：联系方式 12 / 身份信息 10 / 时间日期 9 / 财务金融 8 / 网络技术 18 / 编码编号 13 / 科学医疗 8 / 交通运输 6 / 地理位置 4 / 体育娱乐 3 / 商业企业 3 / 编程开发 3 |
| 自定义规则 | 自己的正则规则可增删改，编辑时实时测试与语法校验；删除前会检测是否被模板引用 |
| 数据预览 | 表格视图（还原合并单元格）与卡片视图双模式，先看前 10 行，导出仍是全量 |
| 数据去重 | 整行去重（免费）或按指定键列去重（Pro）；重复组可展开核对，支持撤销恢复 |
| 表格合并 | 检测相邻可合并的表并链式合并；交界重复行三档策略（保留全部【默认】/ 去除下表重复 / 去除上表重复） |
| 表格统计（免费） | 选中表格即可对其数值列统计：15 项指标分四组页签（基础 6 项默认开，高级/分位数/分布可在设置开启）；整体 / 按列 / 按行三档范围 + 快照上拖选纳入或排除；算不出来的格子显式写「不可计算」并给原因，不用 0 占位；重复值检测（默认开）会点名可疑的重复数值；统计结果可作为独立区块并入 CSV / Excel 导出 |

## 导出

| 格式 | 说明 |
|------|------|
| Excel (.xlsx) | 手机号、身份证等超长数字强制文本格式，不会变成科学计数法；多级表头还原；可开启「保留网页样式」导出带颜色边框的 Excel |
| CSV | UTF-8 BOM（Excel 打开中文不乱码）；逗号引号正确转义；对 `=`、`+`、`@` 开头的字段加防护前缀，避免公式注入 |
| JSON | 二维数组 / 对象数组两种结构可切换；超长数字保持文本 |
| Markdown | GFM 管道表格；该语法没有合并单元格概念，合并区只保留左上角值、多级表头压平为「上级 > 子级」——要保真合并形态请用 Excel |
| 剪贴板 | 同时写入富文本与纯文本，可直接粘进表格软件 |
| 脚注标记剥离 | 「移除脚注标记」默认开启：导出与预览会去掉单元格末尾的 `[1]`、`[a]`、①、※ 这类标记；方括号年份编号（`[2024]`）、两位字母缩写（`[OK]`）等真内容原样保留；关闭后输出与原始采集逐字节一致 |
| 文件名 | 默认 `YYYY-MM-DD_HHmm_TableFlow.{ext}`（本地时区）；「导出前可修改文件名」默认开启，可直接改基本名，扩展名由系统按所选格式自动补齐，不合规只报错不改写 |

## 批量当前页采集导出（Pro）

勾选多张表一次采完再导出，不必逐张走四步。每张表串行采集、状态与行数实时可见，单表失败不影响其余表。交付方式二选一：**一个文件多 Sheet**（Excel / JSON / Markdown）或**压缩包每表一个文件**（Excel / CSV / JSON / Markdown，包内附 `_采集完整性.txt` 逐表核对）。设置页的导出设置（脚注剥离、强制文本格式、文件名编辑）对批量导出同样生效；批量导出保留单元格合并结构，不保留字体颜色与背景色。

## Excel 填充网页

与采集方向相反的第二条工作流：把本地 Excel 的每一行，按顺序**填进网页表单**，适合 ERP 单据起草、订单/库存录入这类重复录入。网页的校验与最终提交仍由你掌控——扩展不会替你点「提交」。**单页批量填写免费**；自动翻页与采集共用免费机会；填充模板是 Pro。

四步：**选择表格 → 设置填充行列 → 检查映射 → 批量填充**，步骤条与采集模式一致，可点回前一步查看和修改。

- **第一步 选择表格**：导入 `.xlsx`/`.xls`/`.xlsm`，范围用五项输入——**开始列、结束列、开始行、结束行、表头行**。默认包含表头（取已用范围第一行），无表头时取消勾选并重新核对开始行；非法或倒序范围会提示并禁用下一步。可跳过隐藏行列，水平合并单元格按**一个逻辑列**处理，只取合并区左上角的值。
- **第二步 设置填充行列**：三个方式按钮都带可见的「行 / 列 / 字段」短标签。**列选择**依次点击可填位置连续选多列；**行选择**点一行里任意可填位置即选中该行全部可填字段；**逐个字段**每次点一个，**可跨行、跨表挑选**（只提醒不拦截，填充前才校验）。
  - **同一列选多行会自动识别为「行 × 列」区域**——行是记录、列是字段，第 N 条 Excel 记录写第 N 行，不会串列；标题实时显示「已选 N 行 × M 列 · 共 K 个单元格」。区域填完即暂停，剩余记录可翻页继续或扩大选择。
  - **单击选择，再次单击取消**；**关闭浮动面板不会结束拾取**，收起期间继续点网页目标仍会被记录，重开即可看到。
- **第三步 检查映射**：双列展示「Excel 逻辑列 ↔ 网页目标」，每行源列下拉都可选 **「None（不填充）」**，没有可写控件的目标自动默认 None 并跳过。下方是**最多前 10 行 × 前 10 列的对照表**，每个已选目标并列显示 Excel 值与真实网页原值；源范围、隐藏行、映射与所选网页行顺序都参与对照。源范围或选择变化后需点刷新重读网页原值。停止说明会具体到行号与原因（如「第 3 条网页行的列数或合并结构与上一条不同」）。
- **第四步 批量填充**：点「开始批量填充」自动逐行写入，可暂停、继续或取消。映射为 None 的目标与空单元格一样不触碰网页控件。支持可写的文本/日期/数值 input、textarea、原生 select、简单 contenteditable 与选项可验证的 ARIA combobox/listbox。
  - **自动翻页**：与采集共用下一页按钮、页码序列识别、手动拾取与翻页验证；每个新翻页批次消耗一个共享机会，暂停继续不重复扣减。达到最大页数或无法确定下一页时暂停，并写明**剩余记录数**。
  - **填完后再开始新一轮**：上一轮填完后重选目标或改映射会自动回到 Excel 第 1 行，避免对照表变成空表。
- **类型化写入**：Excel 日期写进日期控件就是 `2026-10-16`，分组金额写进数字控件就是 `1200.50`；有歧义的文本不猜。
- **下拉严格匹配**：去两端空白、区分大小写的**唯一**启用项命中才算成功，禁用项不参与；集合预检默认开启，不一致时按设置询问、跳过字段或停止。
- **失败不推进**：预检发现不可写控件或待确认项时整条记录零写入；运行中按字段写入并回读，遇拒绝立即停止。空单元格跳过不触碰网页控件。
- **撤销上次填充**：可在同一会话内恢复本次写入前的值（含下拉拍扁），前提是文档、控件身份与写后值都未变。
- **填充模板（Pro）**：指定表头行后可保存、重命名、删除模板，只存范围、映射与目标定位，不存数据行和下拉选项。恢复时按 Sheet、字段数、表头顺序与网页区域匹配；恢复后仍进检查映射，**不会自动填充**。免费用户在成功填完一行后会看到带锁的升级说明，填充前不显示。
- **本地解析、不上传**：不执行 VBA/宏/公式，不自动提交，不新增权限，不把工作簿长期写入扩展存储
- 适用边界见[适用范围与边界](/table-flow/scope)；完整操作见[使用指南](/table-flow/usage-guide)

## 自动化与配置

| 功能 | 说明 |

## 界面与交互

- **四步流程**：① 选择表格 → ② 配置列 → ③ 预览与去重 → ④ 导出；顶部步骤条可点击跳转（受守卫约束，未选表不能进列配置）
- **模式切换**：面板头部可在「采集网页数据 / Excel 填充网页」之间切换，两条工作流数据互不干扰
- **浮动面板**：Shadow DOM 隔离、固定最高层、不挤压页面内容；ESC 可关
- **FAB**：48px 浮动按钮，可拖拽，位置持久化，可在设置里重置
- **欢迎页**：安装后自动打开——上手入口、教程与场景边界、隐私政策链接集中一处
- **状态与提示**：底部状态栏实时显示已采集条数；Toast 覆盖暂停/继续/终止、翻页结束、导出成功、操作失败
- **明确告知不支持的页面**：`chrome://`、扩展商店等浏览器禁止注入的页面，面板会直接说明原因
