# TableFlow 使用指南

TableFlow 是一款 Chrome 浏览器扩展（MV3），用于从网页表格中提取、预览、去重并导出数据。

当前版本（v2.0.1）支持：原生表格扫描、框架表格识别、**虚拟滚动表格检测与滚动全量采集**、列表型表格采集、列选择与配置、识别列（内置+自定义规则）、自动翻页采集、数据预览与去重、断线续采（含行级检查点）、模板系统（含自动检测）、自定义规则管理、嵌套/跨域 iframe 表格采集、**Excel 填充网页（Pro）**、**表格统计（15 项指标、范围与拖选排除、统计导出）**，以及 Pro 订阅体系（激活码 + LicenseHub 在线验证；月付 ¥5 / 年付 ¥40）。Chrome 应用商店与 Edge 加载项安装的版本由浏览器自动更新；压缩包用户可通过应用内更新检测获取新版本（详见下文「自动更新」）。v2.0.1 统一表格接入架构并新增调试控制台 Grid 画像；v2.0.0 新增 Excel 填充网页（Pro，见下文「Excel 填充网页」）、表格统计与设备身份记账加固；v1.6.0 新增完全离线激活（离线授权文件，仅 Pro，见下文「离线激活」）、页码序列翻页、单元格表单控件所见即所得读取与调试控制台网络取证。

## 安装与加载

### 商店安装（推荐）

TableFlow 已在两家浏览器官方商店上架，安装后由浏览器自动更新：

- **Chrome 应用商店**：<https://chromewebstore.google.com/detail/tableflow/cgliggkiiecdmideilajldhdmhpaiepj>
- **Edge 加载项**：<https://microsoftedge.microsoft.com/addons/detail/tableflow/iedocnmbkmhoeccfdoilabeffkncbhmn>

打开上面的链接，点「添加至 Chrome」/「获取」即可，不需要开发者模式。

### 压缩包安装（其他 Chromium 内核浏览器 / 离线部署）

前置条件：Chromium 内核浏览器（Chrome / Edge / 360 极速等）。

1. 从 [Gitee 发布仓库](https://gitee.com/pikachuprogrammer01/my-software-releases/releases) 下载 `table-flow-v<版本>.zip` 并解压
2. 打开浏览器，地址栏输入 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择解压后的 `dist-chrome/` 目录

### 源码构建安装（开发与调试）

1. 下载项目并构建：

```bash
git clone <仓库地址>
cd table-flow
pnpm install
pnpm build
```

2. 打开浏览器，地址栏输入 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目目录下的 `dist-chrome/` 文件夹

### 验证安装

- 浏览器工具栏出现 TableFlow 图标
- 打开任意包含表格的网页，点击图标打开浮动操作面板
- 面板中显示该页面的表格列表

## 自动更新

> **商店安装**（Chrome 应用商店 / Edge 加载项）由浏览器自动更新，无需任何操作；本节适用于**压缩包安装**（其他 Chromium 内核浏览器、离线部署，通过 `table-flow-v<版本>.zip` 手动加载）。商店地址见上文「安装与加载」。

### 更新检测

- 打开浮动面板时自动检测一次（距上次成功检查 ≥6 小时，避免频繁请求）；发现新版本时面板顶部显示横幅「发现新版本 vX」
- 点击「查看更新」打开新压缩包下载地址；点击「忽略」后该版本不再提示

### 更新设置

设置 → 更新：

- **自动检查更新** 开关：默认开启；关闭后不再自动检测（也不显示横幅）
- **检查更新** 按钮：随时手动检测，结果内联展示（已是最新 / 发现新版本 + 去下载）

### 安装新版本

> 商店安装无需手动操作：浏览器会在后台自动更新到商店已发布的最新版。以下步骤只适用于压缩包安装。

1. 下载新压缩包并解压
2. 打开 `chrome://extensions/`，点击 TableFlow 卡片上的刷新图标（⟳），或移除旧目录后重新「加载已解压的扩展程序」
3. 确认版本号已更新

## 快速上手

一次完整的导出流程：

1. 打开包含表格的网页
2. 点击工具栏图标打开 TableFlow 浮动操作面板
3. 在表格列表中选择一个表格
4. 勾选需要导出的列（可按需拖拽排序）
5. 点击「下一步」进入预览
6. 确认数据无误后，选择导出格式并导出

## 详细操作说明

### 第一步：选择表格

打开浮动操作面板后，TableFlow 会自动扫描当前页面的所有 `<table>` 元素。

**列表信息：**

- 每个表格项显示：序号 + 前 2 行内容预览 + 列数/行数
- 框架表格（Element UI / Ant Design / Bootstrap / Element Plus el-table-v2 等）会自动识别并正确读取
- 虚拟滚动表格旁标注「虚拟列表」；采集时会自动滚动视口，尽量读全量行（样式矩阵在虚拟采集下为空）
- 列表最多显示 20 个表格，超出部分不展示

**选中表格：**

- 点击列表项选中对应表格
- 页面上的表格会显示蓝色实线外描边（6px outline，带脉冲动效，便于确认选中的是哪个表格）
- 切换选中时，旧高亮自动移除，新高亮添加
- 列表项左侧的复选框用于「批量当前页采集」：可勾多张表一次采完再导出（Pro，见下文）

**注意事项：**

- 切换浏览器标签页时会自动重新扫描该页面的表格
- 页面 DOM 变化时不会崩溃，点击「刷新」按钮可重新扫描
- 若页面无可用的 `<table>`，面板显示「未检测到表格」
- 打开 `chrome://` 等特殊页面时，面板显示不可用提示，不崩溃

---

### 第二步：列配置

选中表格后进入列配置界面。

**基本操作：**

- 默认全部列已勾选
- 可单独取消/勾选列（至少保留 1 列）
- 「全选」和「反选」快捷按钮
- 拖拽列名左侧的手柄可调整导出顺序
- 浏览器不支持拖拽时，提供上移/下移箭头按钮替代

**识别列（v0.2）：**

识别列功能允许你为已有列挂接正则规则，预览阶段按规则对该列数据做验证。

内置规则：97 条识别规则，分 12 个分类（联系方式 / 身份信息 / 时间日期 / 财务金融 / 网络技术 /
编码编号 / 科学医疗 / 交通运输 / 地理位置 / 体育娱乐 / 商业企业 / 编程开发）。

配置识别列的步骤：

1. 在列列表对应行勾选「识别」
2. 点击该行的「选择」按钮打开规则选择器（支持搜索、热门推荐、分类展开）
3. 选定规则后挂到该列，预览时列头显示规则名标签
4. 采集完成后，预览页对该列执行正则验证（全部命中 / 部分命中 / 全部未命中）

**自定义规则（v0.5）：** 除了内置规则，你还可以创建自定义识别规则，在规则选择器内单独成区。详见[自定义规则管理](#自定义规则管理)章节。

**自定义列（v1.0）：**

在列配置界面点击「+ 新增列」按钮，可添加自定义空列（使用 `_custom_` 前缀标识）。新增列支持编辑列名和删除，适用于手动填写额外数据的场景。

**采集模式：**

- 「仅当前页」：只采集当前页面的数据
- 「自动翻页」：自动翻页采集多页数据（需要页面支持翻页）
- 翻页模式下可设置最大采集页数（默认 50 页，**自本次运行的起始页起算**；翻页到末页或数据为空时自动停止）

---

### 第三步：数据预览与去重

采集完成后或加载已有数据后进入预览界面。

**预览界面：**

- 展示前 10 行数据，超出部分显示「… 共 N 行」
- 两种视图可切换：
  - 表格视图：行列对齐，与最终导出效果一致
  - 卡片视图：每行数据展示为一张卡片，字段垂直排列
- 识别列的列头背景为蓝色，与原始列区分

**去重功能（v0.3 / v1.0）：**

预览页提供两个去重按钮：

- **「去重」**：点击后自动检测整行重复，弹出对话框展示重复组
- **「高级去重」**（v1.0 独立按钮）：直接打开带列选择界面的对话框，可指定「去重键列」，只比较选定列的值

常规操作：

- 默认模式：整行数据完全相同时判定为重复
- 检测到重复时弹出对话框，展示重复组详情（可点击展开组内各行）
- 未发现重复时仅 Toast「未发现重复数据」，不打开对话框
- 点击「一键全部去重」：每组保留第一条，其余删除
- 点击「忽略，直接导出」：关闭对话框，留在预览步继续导出
- 去重后可点击「恢复原始数据」还原全部行

**界面操作：**

- 「返回修改」：回到列配置界面
- 「去重」：触发整行去重检测
- 「高级去重」：指定列进行去重（v1.0）
- 「确认导出」：进入导出格式选择

### 第四步：导出

选择导出格式并执行导出。

**支持的导出格式：**

| 格式          | 特点                                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Excel (.xlsx) | 首行粗体列名，手机号/身份证强制文本格式，列宽自适应；支持「保留网页样式」开关（v1.0），开启后保留背景色/字体/合并单元格 |
| CSV           | UTF-8 BOM 编码，Excel 直接打开中文不乱码，自动处理逗号和引号；格式本身没有合并单元格概念                                |
| JSON          | 两种结构可选：数组格式或对象格式（含元数据），格式化输出                                                                |
| Markdown      | GFM 管道表格；语法没有合并单元格，因此合并区只保留左上角值、多级表头压平为「上级 > 子级」一行。要保真合并形态请用 Excel |
| 剪贴板        | 同时写入 HTML 表格和纯文本两种格式，粘贴到 Excel 列自动对齐                                                             |

**导出后：**

- 导出成功后可点击「保存为模板」将当前配置保存

**移除脚注标记（默认开）：**

公示/法规类页面常在单元格末尾带 `[1]`、`[a]`、`①`、`※` 这类脚注标记。导出步骤的「数据清理 → 移除脚注标记」开关（默认开启，与设置页同名开关联动，可关闭）开启后，导出与预览会去掉**单元格末尾**的这类标记；方括号编号（如 `〔京0106〕[2024]`）、两位字母缩写（如 `[OK]`）与后面还跟着文字的标记都会原样保留。采集数据本身不改，关闭开关导出的文件与原始采集逐字节一致。

**自定义文件名：**

设置页「导出设置 → 导出前可修改文件名」默认开启，关闭时使用默认名 `YYYY-MM-DD_HHmm_TableFlow.扩展名`（日期和时分为本地时区，时分为 24 小时制）。开启后导出步骤会出现文件名输入框，预填默认基本名 `YYYY-MM-DD_HHmm_TableFlow`，可直接改；清空则回落默认名。**输入框只填名字本身，扩展名由系统按所选格式自动添加**——手滑写上了已知格式后缀（如 `.csv`）也会被剥掉换成正确的，最终文件永远是所选格式的扩展名。

文件名不合规时**不会自动改写**，而是禁用「立即导出」并在输入框下方逐条说明原因：不能为空、不能含 `\ / : * ? " < > |` 或控制字符、不能是 `.` / `..`、不能过长。剪贴板不落盘，因此不显示该输入框。

### 批量当前页采集导出（Pro）

一次采集并导出当前页面的多张表，不必逐张走四步。

**入口**：第一步「选择表格」页勾选多张表（列表项左侧的复选框）→「开始批量采集」。免费版该入口为 🔒 锁定状态。

**采集结果**：每张表逐条串行采集，列表实时显示每张表的状态与行数；某张表失败会显示失败原因，不影响其余表继续。采集完成后出现「导出批量结果」区。

> 批量结果只保留在面板内存里，不写入缓存——关闭面板或重新扫描页面后需要重新采集。

**两种交付方式**：

| 方式                     | 产物                       | 可用格式                      |
| ------------------------ | -------------------------- | ----------------------------- |
| 一个文件多 Sheet（默认） | 一个文件，每张表一个 Sheet | Excel / JSON / Markdown       |
| 压缩包（每表一个文件）   | 一个 zip，每张表一个文件   | Excel / CSV / JSON / Markdown |

- 压缩包至少要 2 张表才可选；只勾 1 张表时该按钮置灰并说明原因。
- CSV 只在压缩包方式下提供：把多张结构不同的表塞进同一个 csv 文件没有合理形态。
- 剪贴板不参与批量导出，因此不出现在格式行里。
- 压缩包内文件默认按 `01_表名.xlsx` 命名，顺序与你勾选的顺序一致；重名的表靠前缀区分，不会互相覆盖。
- **设置页的导出设置对批量导出同样生效**：「移除脚注标记」（默认开，包内条目与分 Sheet 都会剥离末尾标记）与「强制文本格式」（默认开，Excel 成员全列文本化、超长数字无精度丢失）。关闭任一开关后批量导出与单表导出行为一致地回落。
- 打开设置页「导出前可修改文件名」（默认开启）后，导出区会出现文件名输入框：分 Sheet 方式 1 个（输出文件名），压缩包方式 1 + N 个（压缩包名 + 包内每个文件）。**只需填名字本身，扩展名由系统按所选格式自动添加**（例如选 Excel 时填 `订单` 会落盘为 `订单.xlsx`）。名字不合规或包内重名时**导出按钮直接禁用**并逐条列出原因（重名会同时标红冲突的两格），不会自动加后缀或改字。

**合并单元格**：批量导出保留单元格合并结构（与单表导出同一套还原逻辑），但**不保留网页里的字体颜色与背景色**——这是当前版本的既定边界，导出区会按所选格式明确写出。虚拟滚动 / ARIA 类型的表格本身不返回合并信息，那类表导出后仍是展开形态。

**结果不完整时**：任何一张表没进文件（或没采到行），导出提示会给出数量与首个原因，压缩包内另附 `_采集完整性.txt` 逐表列明。不会出现"提示成功、实际少几张"的情况。

## 模板系统

模板系统（v0.4）允许你将列配置、识别列设置、采集模式和导出格式保存下来，下次访问同域名或同页面时自动匹配并应用。

### 保存模板

导出完成后，点击「保存为模板」按钮：

1. 输入模板名称（必填，最长 30 字符）
2. 选择匹配维度：
   - 按域名：该域名 `example.com` 下的所有页面共享此模板
   - 按完整 URL：仅当访问完全相同的页面时才匹配
3. 点击确认保存

**模板保存内容：**

- 列选择（已勾选的列名及顺序，包括自定义列的标记与位置）
- 识别列配置（列名 → 规则ID 映射）
- 采集模式（当前页/翻页）
- 最大采集页数
- 导出格式
- 去重键配置

### 应用模板

当你再次打开包含表格的页面时：

1. 面板顶部显示横幅：「检测到 N 个匹配模板」
2. 点击横幅展开模板列表
3. 列表项显示：模板名 + 保存时间 + 匹配维度标签（域名/URL）
4. 点击模板名即可应用
5. 在模板管理页中，匹配当前页面的模板会自动高亮并分组到「匹配当前页面」区域，方便快速定位

**列不一致处理：**

- 如果当前表格的列名和模板保存时不一致，会弹出对话框
- 列出未找到的列名
- 提供两个选项：「忽略未找到的列，继续应用」或「取消」

### 管理模板

在面板中通过导航进入模板管理页（TemplateManageView）：

- **查看列表**：所有已保存模板以卡片形式展示
- **自动检测**：面板会根据当前页面 URL 自动识别匹配的模板，将模板分为两组：
  - **匹配当前页面**（蓝色高亮边框）：与当前域名或完整 URL 匹配的模板优先展示
  - **其他模板**：不匹配当前页面的模板以普通样式展示
- **重命名**：修改模板名称
- **覆盖更新**：用当前的列配置覆盖已保存的模板配置
- **删除**：二次确认后删除模板，不可恢复

**存储空间：**

- 模板存储在 `chrome.storage.sync`，总容量上限 100KB
- 使用量接近 80KB 时，顶部会显示存储空间预警
- 建议定期清理不再需要的模板

## 翻页采集

翻页采集适用于分页列表类的页面；同域虚拟滚动表支持页内暂停与断点续滚。

> **免费版限制**：自动翻页当前默认授予 **5 次采集流程**（每次流程页数不限，中断/刷新同样消耗次数），实际可用额度以服务器为准，平台追加授予也可正常使用。额度耗尽后，每次手动发起翻页会在预算允许时重新检查平台余额，重置或补发后自动恢复；滚动 24 小时最多十次耗尽状态网络请求，恢复重试与注册也计入，网络失败不会退还名额。关闭面板或重启浏览器不重置预算；没有后台轮询，旧请求到期后在下次操作释放名额。订阅 Pro 可解锁无限翻页。免费额度按设备识别，卸载重装且指纹未变时沿用原额度。

### 启动翻页采集

1. 在列配置界面将采集模式切换为「自动翻页」
2. 设置最大采集页数（默认 50 页，**自本次运行的起始页起算**：在第 51 页发起、填 50 就是采第 51～100 页）
3. 点击「下一步」
4. 弹出翻页确认框，确认后开始采集

### 翻页按钮识别

按以下优先级识别翻页入口（受设置页「页码分页器」总开关与列配置页细档影响）：

1. 用户手动选择（点击页面上的下一页按钮或任意页码数字，30 秒无操作自动取消）
2. 通用自动识别（检测「下一页」「›」「next」等文字或 class）
3. 页码序列分页器：页面没有「下一页」按钮、只有 `1 2 3 … N` 数字页码时，自动按页码顺序采集——每轮点击当前页的下一页码，末页自动结束；页码窗口滑动、组件重建均可自适应，误点会被页码连续校验拦截并暂停保护已采数据
4. 加载更多：页面底部是「加载更多 / Load more」类按钮时自动识别。按**新增行数**推进：每点一轮只把新长出来的行计入，旧行不会重复；按钮消失/禁用、滚动触底零新增、或连续 2 轮点击都没有新行时，按数据末尾自动停止，终止原因与累计行数写入采集结果提示。轮数与页数相互独立（不受"最大页数"限制，单次默认 200 轮，触顶暂停并保留已采数据，可继续采集）。不想用这类入口时，可在「设置 → 数据设置 → 采集设置 → 加载更多采集」关闭（默认开启），关闭后不再自动识别，需要时仍可手动点选

**拾取到数字页码时**会弹确认框：「按页码序列采集（推荐）/ 仍用固定按钮 / 取消」。

### 设置：页码分页器

总开关在「设置 → 数据设置 → 采集设置」，**默认开启**；列配置页的采集模式区只保留并存时的细档（仅当总开关为开**且翻页方式为自动识别**时渲染；手动选择的翻页形态由用户拾取决定，不出现该行）：

| 总开关       | 行为                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 开启（默认） | 页码序列参与翻页形态仲裁；可在列配置页选「优先下一页（默认）/ 优先页码」 |
| 关闭         | 完全不使用页码序列模式（行为与旧版本一致），列配置页不再出现该细档       |

| 细档               | 行为                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| 优先下一页（默认） | 启动时有下一页按钮用按钮；按钮缺失/禁用且页码可用时，采集中自动切换到页码序列 |
| 优先页码           | 页码序列优先；页码不可用时自动回落下一页按钮                                  |

两种细档都是「偏好 + 运行时自动切换」而非绝对：采集中一种形态不可用会自动重检测切换到另一种（每轮至多一次），只有两种形态都穷尽才判定末页。该设置只对自动识别生效；手动拾取的页码确认框不受此设置限制。

免费版额度按「流程」计数：一次页码序列采集与一次下一页按钮采集一样各计 1 次（默认授予 5 次，实际以平台额度为准），流程内页数不限。

### 暂停 / 继续 / 本页重采

- **暂停**：同域表可立刻停止页内滚动或按行确认；已采行保留并落盘
- **继续**：未采完整的页从断点补剩余（不默认整页重采）；已封页则翻到下一页
- **本页重采**：仅当本页未封完时出现；丢弃本页草稿后从顶重新采本页（封页失败时的兜底）
- **跨域 iframe 表**：本页读取不可中断，暂停将在本页读完后生效

### 安全机制

- 可设置最大采集页数（默认 50 页，**自本次运行的起始页起算**，翻页到末页、数据为空或达到该页数时自动停止）。**触达上限时结尾信息会明说「已达最大采集页数上限…本次自起始页起算…数据可能未采全」**，不会用一句「采集完成」让你以为已经采全；站点实际条数超过该页数时，请调大最大采集页数后重新采集
- 检测到最后一页（按钮 disabled 或消失；页码模式下当前页码已达实时末页）自动停止
- 可随时点击「暂停」或「终止」（均有 Toast 反馈提示）
- 翻页按钮找不到时 Toast 提示，引导用户手动选择（也可点击任意页码数字切换为页码序列采集）
- 翻页结束（按钮禁用 / 明确末页 / 页码序列到底）时 Toast 告知结束原因；合法重复数据页会继续采集，不会被误判为末页。内容与**紧邻上一页**相同照常放行（真实换页会重建行节点，即使数据恰好相同）；只有内容与更早的页面循环重复、且页码推进也证明不了这是新的一页时才暂停
- 翻页超时或定位失败会暂停并保留断点，可检查当前页后继续，而不会伪装成已采完；页码模式下若实际页码与预期不符（防窗口滑动点错号）同样暂停保护，不跳页漏采。**有且只有一次例外，且只在本轮第一次翻页**：若页面实读页码**领先于**面板计数器（从暂停处「继续」时多半是上一轮那次点击其实落地了；在站点中途页新发起采集时则是计数器把起始页当成了第 1 页），扩展按实读页码对齐后继续，而不是让你反复点「继续」却每次都回到同一个暂停。第二次及以后的失配、以及回绕到更小页码（如内部第 7 页而实读第 1 页）仍按原样暂停——那是计数器漂移或跳页，必须停下
- **页码动了但表格内容纹丝不动**（翻页入口与表格不联动、或数据一直没加载回来）会**单独归因**暂停并提示核对/重拾翻页入口，不再笼统报「无法确认页面已更新」——这类站点只挪 active 页码、表体不动，继续采会把同一页反复采进去（可能出现"页码一路涨、结果 500 行里 480 行重复"）
- 虚拟页须「封页」证明完整后才允许翻下一页，避免残缺页脏翻页

### 单元格里的输入框/下拉框

表格单元格内如果嵌有输入框、下拉选择、文本域（包括只读 readonly 与禁用 disabled 状态），
采集时一律按**页面上当前可见的值**导出：编辑过的内容不会被漏采或采成旧初值；
联想候选（datalist）等页面看不到的内容不会混进单元格。密码框固定输出为脱敏点号，
隐藏域（type=hidden）因用户不可见不采集。预览页统计栏会显示「已按显示值读取 N 个表单单元格」。

### 翻页确认框

翻页模式下点击「开始采集」后会弹出确认框，提示将从当前页开始采集。手动选择模式下不做自动检测，仅验证已选定的翻页入口（选择器/签名），入口已变化时提示重新点选。

## 断线续采

断线续采允许你在采集过程中关闭 Panel 或暂停后恢复；支持**页内断点**（未采完的当前页可续）。

### 触发条件

再次打开 Panel 时，如果检测到未完成的采集缓存，顶部显示横幅。未封完的页会标明「第 N 页未封完」。

**已完成的结果同样会进横幅。** 页面刷新、跳转，或站点把整页换成登录页/会话超时页之后，面板内存里的数据会清空，但已采集的结果快照仍写在本地缓存里——此时横幅显示「上次采集已完成（N 条）· 页面刷新或跳转后数据已保留，可直接导出」，点「直接导出」直进步骤 4，不再经过预览。这类快照只能导出或丢弃，不提供续采。缓存按标签页存放，同一标签页重新打开该站点即可找回。

### 操作选项

| 操作                | 说明                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| 继续采集 / 继续本页 | 按检查点 `pagePhase` 对齐：已封页先翻页；`next_ready` 直接读已进入的下一页；未封页同页续采已确认之后的行 |
| 直接导出已采集 N 条 | 跳过采集，直接加载已缓存的数据：未完成态进预览（含未封页时会提示可能不完整），完成态直进步骤 4 |
| 丢弃重新开始        | 二次确认后清除缓存，从第 1 页开始全新采集                                                                |

### 缓存说明

- 采集过程中经单写者队列写入 `chrome.storage.local`（含页内检查点）
- 缓存接近 5MB 时会提示建议先导出

## 表格统计

选中表格并采到数据后，就能对它的数值列做统计。统计是**面板内的一个子视图**：点面板头部的「统计」按钮进入，关闭即回到原来的采集步骤；
它不叠在页面之上，因此不会挡住「选择表格」的卡片。

### 统计的是什么数据

算的是**这份采集结果快照**——也就是你在预览里看到、导出时会写进文件的那批格子，不是页面上所有看着像数字的东西。
好处是口径唯一：统计里出现的行，导出里一定在；页面还没采进来的行，也不会偷偷参与计算。

### 指标与分组

| 页签 | 指标 | 默认 |
| ---- | ---- | ---- |
| 基础统计 | 计数、求和、平均值、最小值、最大值、极差 | ✅ 开 |
| 高级统计 | 中位数、标准差、方差、众数 | 关 |
| 分位数 | 下四分位、上四分位、四分位距 | 关 |
| 分布 | 偏度、峰度 | 关 |

要一次开满 15 项：「设置 → 统计分析 → 套用预设 → 完整」。

### 范围：整体 / 按列 / 按行 / 拖选排除

- **整体**：把选定范围内的全部数值格子当成一个样本集，出一套结果。
- **按列 / 按行**：为每个分组各出一套结果与样本量（默认口径下每列一套，与你在表格里看到的列一致）。
- **拖选**：在表格快照上按住拖动可框出矩形范围，顶部开关决定「只算这块」还是「不算这块」；支持多次拖选累加，也可逐格取消。
  面板会显示纳入 / 排除 / 数值 / 跳过四个计数，方便核对"到底算了多少个格子"。

### 算不出来的格子

以下情况格子显示「不可计算」并给出原因，不会显示 0 或 `NaN`：没有任何样本、选定范围里没有一个能解析成数字的值、
样本量不足以计算该指标（如只有一个值时算标准差 / 方差）、所有值都只出现一次（无众数）、计算分母为 0。
数字解析按页面显示的文本走（千分位、货币符号、百分号、全角数字等），**遇到区域写法有歧义时按非数字跳过**——宁可少算，不猜数。

### 重复值检测（默认开）

分组结果下方有一行「重复值检测」，判的是**当前分组在你所选范围内的有效数字**（与旁边的「样本数」同源，
不跟着某个指标的独立范围变）：

- 唯一值太少，或某个值重复占比过高 → 标为「可疑」并点名那个值（例如 `值 1 重复出现 10 次（50.0%）`），
  意思是这批数字可能被人为填充或有录入错误，值得回头核对来源；
- 分布正常 → 显示唯一值比例；
- 本组数字不足 10 个 → 直接写「样本量过小（<10），无法进行重复值检测」，不会把「没做检测」显示成「没有异常」。

设置页「统计分析 → 数据完整性检测」里可以关掉它。关掉后这一行消失，**15 项指标的数值一条都不变**——
检测只是附加结论，不参与任何统计口径。同一页里另外五项（Benford 定律、末位数字、占比异常、单调性、多样性）
标着「暂未接入」：勾选状态会被保存，但当前不参与计算，所以也不会在面板里出结果。

### 大表格

万行级表格的统计在扩展的后台页面里计算，面板只显示进度与结果，采集流程不被卡住；
收起面板、切换表格或修改范围会取消进行中的计算，旧结果不会串到新的范围上。相同范围的重复请求直接复用已算结果。

### 把统计结果带走

- **并入导出**：在导出步骤选择带上统计结果，它会作为独立区块写进同一个 CSV / XLSX 文件。
- **配置带走**：「设置 → 统计分析 → 导出配置」生成带版本号的 JSON；「导入配置」兼容带注释（JSONC）、带 BOM 的旧文件与更早版本的裸配置。

### 统计的边界

- Canvas 画出来的表读不出文字，因此没有可统计的数值。
- 跨域 iframe 里的表能采集能导出，但其帧内数值列的统计尚未在真实站点上端到端验证（见「适用范围与功能说明」§5.0.2）。
- 统计是页内子视图，不提供停靠、缩放或独立窗口。

## Excel 填充网页

前面几节讲的是把网页上的表格**采下来**。「Excel 填充网页」是方向相反的第二条工作流：把本地 Excel 的每一行，按顺序**填进网页表单**，用于 ERP 单据起草、库存录入、采购入库这类重复录入。网页的校验与最终提交仍由你掌控——扩展不会替你点「提交」。

**入口**：面板头部的模式切换（`采集网页数据 | Excel 填充网页`）切到「Excel 填充网页」。单页批量填写免费；自动翻页与采集共用免费机会，默认五次，实际以平台余额为准。模板仍需 Pro。

### 填充偏好

在「设置 → 数据设置 → Excel 网页填充」可保存以下偏好：

| 设置 | 初始默认值 |
| --- | --- |
| 默认跳过隐藏行 | 关闭 |
| 默认跳过隐藏列 | 关闭 |
| 默认填充后自动下移到下一行（仅真实表格） | 开启 |
| 显示行 / 列 / 单元格选择 | 全部显示，至少保留一项 |
| 下拉选项集合预检 | 开启 |
| 选项不一致 | 询问，可改为跳字段或停止 |
| 本地下拉写入文本 | 跳过，可改为拍扁显示值 |

隐藏行、隐藏列与自动下移这三个默认值在两个宿主的**新会话**开始时采用。当前会话仍可在导入与逐行填充步骤调整；
关闭重开面板、切换模式、重新加载或更换文件保留本次选择。修改这些默认值不会重置当前文件、游标与选项，
会在下一新会话生效。填充正在进行时相关控件不可修改。设置保存失败会显示「设置保存失败，改动尚未保存，请重试。」。

选择入口的显隐会同步到两个宿主，拾取或写入过程中延后变化；隐藏入口不删除已有选择、映射或模板。下拉策略在每次动作开始时冻结，确认继续使用同一份策略。

### 第一步：选择表格

- 选择 `.xlsx` / `.xls` / `.xlsm` 文件。**文件只在本地解析，导入链路不上传**，也不执行 VBA、宏、外部链接或公式。
- 选工作表：下拉里列出全部 Sheet；普通隐藏 Sheet 标注 `(隐藏)`，**仍可选择**，只有极隐藏 `veryHidden` 不可选。默认优先选择可见 Sheet。
- 范围使用五项输入：**开始列、结束列、开始行、结束行、表头行**。列按 Excel 字母填写，行按 Excel 行号填写；范围内每个数据行是一条记录。
- 默认**包含表头**，使用工作表已用范围的第一行作为表头、从下一行数据开始。无表头时取消勾选，重新核对开始行。非法或倒序范围会提示并禁用下一步。
- 两个开关：**跳过隐藏行**、**跳过隐藏列**（按 Excel 里的行列隐藏状态过滤，初始默认均关闭）。改隐藏行会重置源行游标；改隐藏列导致源列结构变化时需要重新确认映射。
- 水平合并单元格按**一个逻辑列**处理，只取合并区左上角的值，不重复产出字段。
- 筛选不会在扩展里重新计算。跳过与否依据文件保存的行列隐藏标记；请先在 Excel 保存，并核对预览和可填行数。
- 公式不重新计算，只读取文件已有的缓存或显示值；依赖公式时先在 Excel 中计算并保存。工作簿仅留在当前宿主文档内存，不是持久备份。

### 一个订单录入例子

工作簿 `订单.xlsx` 的 `订单` Sheet 如下（日期和金额分别为 Excel 日期、数值单元格）：

| Excel 行 | A：订单日期 | B：金额 | C：状态 |
| --- | --- | --- | --- |
| 1 | 订单日期 | 金额 | 状态 |
| 2 | 10/16/26 | 1,200.50 | 待处理 |
| 3 | 10/17/26 | 80.00 | 已确认 |

填写开始列 A、结束列 C、开始行 2、结束行 3、表头行 1。先在目标网页准备两行可编辑订单明细。即使网页列顺序是「状态、日期、金额」，也依次选择**日期列 → 金额列 → 状态列**，使编号 1/2/3 对应 A/B/C。核对映射后启动批量填充，自动逐行写入两张订单。

### 独立页先选择目标网页

在独立页的「目标网页」下拉中明确选择要填写的标签页；新开页面尚未出现时点「刷新网页列表」。未绑定不能拾取或填充，切换其他活动标签页不会改写已绑定目标。切到目标网页拾取，返回独立页检查映射。

更换目标会结束旧批次、清掉旧选格和编号，但保留源文件与已完成进度；先确认当前 Excel 行对应哪条网页业务行，再重选并确认映射，开始新批次。目标页导航、刷新、关闭或连接失效后需重新绑定；同源 iframe 导航后旧目标也失效。不要把旧文档的映射直接用于新页面。

### 第二步：设置填充行列

- 点「开始选择」后，可查看已选字段和目标行，选好后点底部「完成选择，检查映射」（与采集模式同款的「上一步 / 下一步」步骤条）。三个方式按钮都带**可见的「行 / 列 / 字段」短标签**，当前方式高亮；拾取或填充中不可切换。
- **列选择**依次点击任意可填写位置即可连续选择多列；**行选择**点击一行里任意一个可填写位置，就会选中该行**全部可填写字段**（例如 3 个字段一次选中），可连续选择多行；**逐个字段**每次点击选择一个字段，**可以跨行、跨表挑选**。字段选择不做拦截：跨行、跨表、同一列重复选择都能点进去，选择区会给出提醒；真正危险的不规则同列重复会在检查映射页与填充前拦截，不会静默写错。
- **同一列选多行会识别为区域（推荐用法）**：行 = 记录槽位、列 = 字段。例如在 Age 列从上到下点 10 个输入框，会显示「已选 10 行 × 1 列 · 共 10 个单元格」，第 1 条 Excel 记录写第 1 行、第 2 条写第 2 行，同一列不会串到其他字段；多列同理（N 行 × M 列）。区域填完后暂停或按自动翻页继续。
- 标题按当前方式说话：区域是「已选 N 行 × M 列 · 共 K 个单元格」，行模式是「已选 N 行 · M 个字段」，列/逐个字段模式跨行时是「已选 M 个字段 · 跨 N 行」；拾取过程中逐行摘要会实时更新。
- 跨表、不规则同列重复、行队列字段数不同等组合都会以**提醒**形式显示（不拦截选择）。嵌套表格以最近的表格为边界；表单的嵌套字段分组可一起选择。
- **单击选择，再次单击取消**：点已选中的格子/行会把它从当前选择中移除，其余选择保留；不需要先「清除选择」再重选。
- **关闭浮动面板不会结束拾取**：面板收起后继续点网页里的可填写位置，选择仍会被记录；重新打开面板即可看到新增的行/字段摘要。切到其他步骤、切换模式或按 ESC 会结束拾取。
- 「清除选择」只清网页目标，**不动**已导入的文件、Sheet 与 Excel 行指针。
- 拾取过程中切走模式会结束拾取，但**已选目标保留**。

### 第三步：检查映射

双列展示「Excel 逻辑列 ↔ 网页目标」：每项给出源单元格、示例值与网页控件类型。每行的源列下拉都可以选 **「None（不填充）」**，表示这一行/列/单元格跳过、不写入网页；**没有可写控件的目标会自动默认 None**，不会因此挡住整张映射。其余字段可以随意选择：目标数不必等于源列数——少于源列时只填选中的字段，多于源列时允许复用同一源列（例如把同一个 Excel 值写到两个网页字段）。若给「没有可写控件」的目标手动选了源列，检查映射页会指出具体目标并提示改回 None 或重新选择单元格；所有目标都选 None 时没有可填内容，也不能确认。**区域选择按列映射**：选了几列就只出现几行映射（行 = 记录、列 = 字段），对照表也按「记录 × 字段」排列，不会把同一列的多行误当成一条记录的多个字段。规则区域不会触发「同列重复」提醒；不规则选择里的同列重复仍会在填充前被拦截。

下方对照表按当前游标展示**最多前 10 行 × 前 10 列**，每个已选目标并列显示 Excel 值与真实网页原值，可横向滚动；超过上限会明确写出「对照表最多显示前 10 行、前 10 列」。源范围、隐藏行、字段映射和显式选择的网页行顺序都参与对照。当前页不足十行或遇到结构护栏时显示实际行数与停止原因，不读取后续页；关闭自动下移时只对照当前网页行。**停止说明会尽量具体到行号与原因**：例如「第 3 条网页行的列数或合并结构与上一条不同」「第 5 条网页行对应位置没有可写控件」「已到所选区域最后一行」；对照格没有对应记录时写「当前页无第 N 条网页记录」，而不是笼统的「无可用网页行」。**对照到本页最后一行时，说明会给出「当前页可对照 N 条网页记录 / 另有 M 条 Excel 记录」，并提示开启自动翻页或在下一步重新选择网页行**。对照列只铺已选目标；选了 None 的字段标「不填充（跳过该目标）」。对照不会填写、点击、滚动或移动选区。刷新按钮读取时图标转圈并禁用，成功后短暂显示完成态，失败仍可重试。调整源字段映射不会让对照失效，Excel 值会按新顺序立即重排；选择或源文件变化后需点刷新图标重新读取，原值未就绪不能确认映射。

每个网页目标都可更换源字段（可重复选择同一源列，也可留空未使用的源列）。网页填充模板是 **Pro 功能**：Pro 用户始终可见模板区；免费用户在**成功填充至少一行后**会看到一条带锁说明「本次填充已完成，升级 Pro 可保存当前范围/映射/定位」，填充前不显示，免费版点顶部「管理」也会像采集模式一样提示升级。保存区在**至少成功填充一行之后**才出现——不要求「完整映射」，只要当前配置跑通过一次填充即可保存；表头行右侧的空列或重复列不会阻止保存。可在检查映射与逐行填充两步保存、重命名、删除网页填充模板；填充中保存禁用，批次进行中恢复禁用。恢复需重新导入文件并匹配 Sheet、整行有序表头、所选范围和网页区域（含区域首行 + 行数展开、跨行逐字段定位），定位缺失或歧义时重新选择。恢复后仍进入检查映射，**不会自动填充**。填充模板与采集模板分开，只保存范围、映射和定位配置，不保存数据行、选项集合、DOM 或游标；空间不足或写入失败会显示错误。

### 第四步：逐行填充

- 「填充范围」配置块（仅当前页/自动翻页、翻页入口、最大填充页数、手动选择入口）拆成展示组件 `WebFillPaginationPanel`（只接收 props/发事件）与容器组件 `WebFillPagination`（读写 store/license、托管页码分页器确认框），视觉保持原填充模式样式。
- 面板显示文件、Sheet、当前源行与总行数，以及当前待填行的预览。Pro 用户的「网页填充模板」在内容区底部；再往下是**与采集模式一致、固定在面板底部的**「上一步 / 下一步（开始批量填充）」步骤条（内容滚动时始终可见）。保存区只在至少成功填充一行后出现，填充中保存禁用、批次进行中恢复禁用。免费用户整块模板区不可见。
- 点「开始批量填充」后自动逐行填写，可暂停、继续或取消。映射为 None 的目标会被跳过（与空值一样不触碰网页控件），其余字段照常写入并回读。支持可写的文本/日期/数值类 input、textarea、原生 select、简单 contenteditable 和完整选项可验证的 ARIA combobox/listbox。写值后派发事件并回读检查，仍须检查网页业务结果。
- **日期与金额**：示例中真正的 Excel 日期 `10/16/26` 写进 `date` 输入框为 `2026-10-16`，数值金额 `1,200.50` 写进 `number` 输入框为 `1200.50`；写入文本框仍保留显示值。有歧义的文本不会被猜成日期或数值；目标拒绝时会报错并保留当前源行。
- **下拉匹配**：去两端空白、区分大小写，必须唯一命中启用的 value 或显示文字；禁用选项不参与。集合预检默认比较 Excel 与网页的启用显示选项，忽略顺序。差异按设置询问、跳字段或停止；关闭预检仍须唯一合法命中。询问仅在存在唯一命中时提供「按匹配项继续」，缺项、歧义、未知只能跳过或取消。
- **本地下拉到文本**：默认跳过，按设置拍扁时只写当前选中项的显示文本，不拼接整组选项；转换和跳过会单列报告，可撤销。
- **未知验证**：OOXML 支持内联、静态单元格范围、命名范围列表；动态/外部/不支持的验证及 XLS 均标为未知。文件仍可导入；无法验证的**下拉**目标不可强制写入，可按策略跳过，文本、多行文本和可编辑区块等控件照常写入。
- **预检与运行失败**：不可写控件、待确认或停止会在整条记录写入前拦截，零字段写入；运行中按字段写入并回读，遇到拒绝立即停止后续字段。失败源行不推进，先前写入不自动回滚。
- **空值跳过**：源单元格为空时**不触碰网页控件**（输入框保留原值、下拉框不报无匹配），也不拦整行推进，文案会单列「跳过 S 个空字段」——跳过既不是写入也不是失败。
- **逐行推进**：批量模式成功后自动移到下一条目标记录。**区域选择按用户选好的行槽位逐行推进**（第 N 条记录写第 N 行，区域内不会覆盖同一行；区域填完即暂停，剩余记录可开启自动翻页继续或扩大选择）。行模式按所选网页行队列推进；非区域的列/逐个字段模式下每个字段各自向自己所在列的下一行推进。下一行缺列、合并结构变化、控件不可写或遇到合计行时暂停；不规则同列重复、跨表且无下一行等情况在整批写入前拦截。完整成功的记录仍推进源游标，部分失败留在当前记录。普通表单需准备并重选下一条记录。
- **自动翻页**：与采集共用下一页按钮、页码序列识别、手动拾取和翻页验证。每个新翻页批次消耗一个共享机会，暂停继续不重复扣减；默认五次免费机会，实际以平台余额为准。单页填充免费，达到最大页数或无法确定下一页时暂停。
- **调整批次设置**：暂停后可继续原批次；如需更改翻页范围、入口或自动下移，先取消批次，再调整并重新开始。已完成的源记录不会重放。
- **完成**：区域填完或网页已到最后一行，本行成功仍推进源游标；若 Excel 还有剩余，暂停文案会写明**剩余记录数**，并给出「扩大选择」「开启自动翻页」或「重新选择下一行网页单元格」的下一步。全部源行填完后显示完成，检查目标网站的校验与保存结果，再自行保存或提交。
- **填完后再开始新一轮**：上一轮已填完后重新选择网页目标或修改映射，会**自动把源游标放回第 1 行**，检查映射的对照与 Excel 样本重新可见；否则对照表会是一张空表、容易误以为映射坏了。源范围本身没有数据行时，对照区会明确提示返回第一步检查起始单元格/结束行/表头行，并禁用「确认映射」。

### 部分失败后重试

1. 保持当前源行和当前业务行，检查哪些字段已写入、哪些被网页拒绝。空字段被跳过时，网页旧值还在，也需检查。
2. 修复选项、格式或控件；目标重建时清除并重选**当前业务行**，重新核对映射。
3. 重试当前行。它会再次写入所有非空字段，网页的校验、自动保存或网络请求可能再次执行。不要因为已有几个字段成功就跳到下一业务行。

也可点「撤销上次填充」，恢复包括拍扁在内的本次写前值。撤销只保留在当前会话，源文件/映射、文档、控件身份和写后值必须仍匹配；网页已编辑、禁用、重渲染、导航时会拒绝相应字段并报告恢复数。只有全部恢复成功才还原源游标与网页目标位置，不承诺撤回网站已经发出的自动保存请求。

### 重开、重导与刷新后的恢复

- **同一存活会话**：收起/关闭面板后重开、切换模式，保留当前文件、Sheet、映射、游标与会话开关。
- **重新加载文件**：文件名、文件大小、修改时间三项相同才视为同一文件并保留源游标；其他文件从第一行开始。这只是身份判定，不能代替内容核对。
- **源结构变化**：逻辑列标或合并标记改变时，旧映射确认作废、源游标回第一行。**仍有网页目标时会送到检查映射页重新核对；目标已被清空（例如上一批填到页尾）时留在导入/选目标步骤，并提示先重新选择网页目标**，不会展示一页「无可用网页行」。不要假定所有重导都会清映射，也不要认为同名文件总能原样接着填。
- **往回查看**：只有正在填充或批次运行中禁止切换步骤；暂停、完成或目标已清空后，仍可点前面的步骤回去查看与修改，不会被「请先选择网页单元格」拦住。向前跳转仍按原有条件拦截。
- **文档或浏览器重载**：工作簿不写入持久存储，源宿主文档刷新/销毁或浏览器重启后要重新导入并确认起点。独立页存活而目标页刷新时，源文件可能仍在，但目标绑定和选格必须重建。

### 边界

- 支持真实 HTML 表格行和普通 `form` / `role=form` / 独立 `fieldset`；虚拟表格、div / ARIA 网格不在支持范围，采集支持某框架不代表其编辑界面可写。
- 不写只读或禁用控件，不操作 checkbox、radio、file、颜色或滑块输入，不保证复杂富文本与自定义日期/下拉组件可用。
- 真实 `<table>` 之外不做自动下移（div-grid、ARIA grid、虚拟列表）；自动翻页限顶层文档中可重新定位的真实表格。
- 支持 open Shadow DOM 与同源 iframe 的嵌套组合；跨域 iframe、闭合 Shadow DOM 不可写，虚拟或不完整下拉选项不可强制写入。
- 不自动点击「提交」「保存」「下一行」等按钮，也不自动新增行；只有显式开启自动翻页才点击分页入口。`input` / `change` / `blur` 等事件可能触发**目标网页自己的自动保存、校验或网络请求**；不上传原始 Excel 文件不等于网站不会接收填入的字段。先试一行并确认业务影响。
- 普通 HTTP / HTTPS 可用；`chrome://`、扩展商店、内置 PDF 等浏览器禁止注入的页面不可用。
- 不把完整工作簿内容长期写入扩展存储，不新增权限。

## 常见问题

**Q: 表格没有被识别出来？**

A: 点击「刷新」按钮重新扫描。确认表格不是通过 JavaScript 延迟渲染的（等待页面加载完成后再试）。某些复杂框架表格可能需要等待框架组件完全渲染。页面是 `ul/li` 列表的话，确认设置页「数据设置 → 列表识别（ul/li）」已开启；仍不出现时可把「列表识别严格度」放宽到「宽松」再重扫（默认「标准」与历史行为一致）。

**Q: 列表采集出来了，但列名是「列1」「列2」？**

A: 说明这个列表既没有页面自己的列名声明，也没有命中内置规则。到设置页「数据设置 → 列名规则」加一条：点「+ 新增规则」，在「我要识别什么？」里选「日期」「标题链接」这类现成选项（选完条件就自动填好了），填一个列名保存即可，重扫后按你的名字显示。取名优先级是「页面自己写的 → 字段里的「标签: 值」→ 你的规则 → 列N」。

**Q: 导出的手机号变成科学计数法了？**

A: 使用 Excel (.xlsx) 格式导出会自动处理此问题。如果使用 CSV 格式，在 Excel 中打开后请将单元格格式设为「文本」再粘贴。

**Q: 表格只采到看得见的那几行（虚拟列表）？**

A: 卡片带「虚拟列表」徽标的表，采集时会自动滚动逐屏补回未渲染的行，**这一步不需要开启自动翻页**。没有徽标却只采到几行，说明该页面的虚拟形态还没被三层判定命中（常见于尚未适配的组件库），此时只会拿到页面上已渲染的行且不报缺行——请与页面行数核对后展开或重新扫描。超长列表另受按滚动高度动态估算的 200–5000 轮上限约束，触顶会按已采行数交付并给出诊断。

**Q: 页面底部是「加载更多」，能一次点到底吗？**

A: 能。入口会被自动识别（也可在「手动选择」里点选它），采集按「新增行数」推进：每点一轮只把新长出来的行计入，旧行不会重复；按钮消失/禁用、或连续 2 轮点击都没有新行时按数据末尾自动停止，终止原因会写进采集结果提示。采集轮数与翻页页数相互独立，默认单次最多 200 轮，触顶会暂停保留已采数据、可继续采集。导出前建议用行数与页面声明核对一遍。

**Q: 翻页采集没有自动翻页？**

A: 尝试手动选择翻页入口：在点击「翻页模式」开关后点击「手动选择」，然后点击页面上的下一页按钮或页码数字。框架类网站可能需要手动选择。

**Q: 翻页采集中途停了，提示「未能确认已进入下一页」？**

A: 这句话说的不是"页面坏了"，而是"扩展点了页码，却拿不出证据说明确实换到了下一页"。最常见形态是点击后表格先被清空或换成加载骨架，随后又变回原来那一页；也有站点页码数字压根没动。此时采集停在当前页、**已采数据全部保留**：先在页面上核对现在是第几页，点「继续」就从这一页续采；若页面确实一直停在同一页，说明这个入口不可靠，改用「手动选择」点真正的下一页按钮或页码数字。扩展不会因为看不清落点就把同一页重复采一遍，也不会把它当成"已采完"悄悄收场。

还有一种形态单独提示：如果**页码确实动了、表格内容却一动不动**，暂停文案会直接写明"当前翻页入口可能与表格不联动"。这类站点的分页器和表格是两套东西（常见于会话过期后接口静默失败），点它只是在挪高亮。扩展此时不会继续往下采，请按提示到「采集配置 → 手动选择」重新点一个真正联动的入口。

**Q: 采集完成后页面自己跳走了，采到的数据还能拿到吗？**

A: 能。有些站点在采集结束后把整页导航到登录页或会话超时页，面板内存里的数据会随之清空，但结果快照仍写在本地缓存里。回到**同一个标签页**重新打开该站点，顶部会出现「上次采集已完成（N 条）· 页面刷新或跳转后数据已保留，可直接导出」，点「直接导出」即可。缓存按标签页存放，换标签页就找不回来了；这类快照只能导出或丢弃，不会被当成未完成任务继续采集。

**Q: 模板保存后下次打开没匹配到？**

A: 确认模板的匹配维度设置是否正确。按域名匹配只比对 hostname 部分（不含路径和参数），按完整 URL 需要完全一致。

**Q: 模板存储空间不足？**

A: 进入模板管理页清理不再需要的模板。`chrome.storage.sync` 总容量上限为 100KB，每个模板数 KB 不等。

**Q: 自定义规则保存后在哪里使用？**

A: 回到列配置界面，在目标列勾选「识别」并打开规则选择器，自定义规则在选择器内单独成区；选定后像内置规则一样挂到该列。

**Q: 删除自定义规则会影响已有模板吗？**

A: 会。如果模板中有使用该自定义规则的识别列，删除规则后应用模板时会提示「该模板包含已删除的规则」，对应识别列将被跳过。

**Q: 如何验证自定义正则是否正确？**

A: 在新增/编辑规则时，使用正则测试框输入示例字符串即可实时验证。匹配成功显示「✅ 匹配」，语法错误会显示红色提示。

**Q: 免费版翻页次数用完了怎么办？**

A: 免费版默认授予 5 次采集流程（页数不限，中断/刷新同样消耗次数），实际额度以平台为准。平台重置或补发后，再次手动发起翻页会在请求预算允许时恢复。耗尽状态滚动 24 小时最多十次实际网络请求，超时与恢复重试也占名额，重开面板或重启不会清零；请求到期后在下次操作释放名额。订阅 Pro 后解锁无限翻页。

**Q: 如何订阅 Pro？**

A: 点击工具栏「Pro」按钮进入订阅页：微信/支付宝扫码付款（月费 ¥5 / 年付 ¥40）→
添加开发者 QQ 好友，发送付款截图与设备码（备注「TableFlow 订阅」）→ 获取激活码后在订阅页输入激活。

**Q: 激活码可以换设备使用吗？**

A: 一码一设备。激活码在线绑定时与设备绑定；需要换设备时，在旧设备的「账户」页点击「解绑设备」，解绑后激活码可在新设备重新激活。

**Q: 激活 Pro 需要联网吗？**

A: 常规激活（hybrid）：激活码本地验签通过即可解锁（可离线使用）；激活/解绑时需联网完成在线绑定。网络不可达时先临时解锁，联网后后台自动确认。完全断网环境可改用「离线激活」：凭设备码向开发者申请离线授权文件，本地验签即激活（见上文「离线激活」）。无论哪种激活方式，订阅页顶部都常驻展示本设备码。

**Q: 为什么我的模板/识别列/高级去重不可用？**

A: 这些是 Pro 功能，免费版锁定。订阅并激活后自动解锁。
