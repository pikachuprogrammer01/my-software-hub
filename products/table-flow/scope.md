# 适用范围与已知边界

> 来源：`table-flow/docs/SCOPE_AND_FEATURES.md` §一/二/五/六（删去扫描阈值与代码索引章节）。

## 一句话定位

TableFlow 从**浏览器已经渲染出来的 DOM** 上采集数据：支持有适配器或语义证据的原生 `<table>`、div 型框架表格与 iframe 表格，具体见下表；采集范围以网页已渲染的内容为准。除此之外还有一条方向相反的工作流：把本地 Excel 的行**写进**网页表单（Excel 填充网页，单页批量填写免费）。

## 术语速查（给不看技术文档的用户）

| 界面/文档里的词 | 日常说法 |
|----------------|----------|
| DOM / 渲染 | 浏览器按网页代码"画"出来的成品页面。插件只认画好的成品 |
| 原生表格 / div 表格 | 真表格（`<table>`）vs 用小方块拼出来的"仿表格"（Element UI、Ant Design 等框架都这么做） |
| iframe / 内嵌 | 网页里再开一扇小窗，窗里是另一张网页，像画中画 |
| 同源 / 跨域 | 同源＝同一家网站自己的窗，能直接看进去；跨域＝别人家的窗，中间有墙，只能"递纸条"（postMessage） |
| 跨域白名单 | 门禁名单。默认只放行政务类域名，其他站点的窗要在设置里手动放行 |
| 虚拟滚动 | 长列表只画看得见那几行，滚到哪画到哪。像老式电话簿只印当前一屏 |
| 行为探针 | 拿不准是不是虚拟滚动时，插件会"轻轻推一下"列表，看内容有没有换一批，再下结论 |
| 行身份（去重键） | 判断"这一行是不是刚才那行"的依据：优先用 `data-id` 这类行 ID，没有就用"位置 + 文字" |
| 封页 | 判断"这页已经采全了"才允许翻下一页；判断不了就停下来问你，而不是悄悄漏采 |
| 检查点 / 断点续采 | 下载断了能续传，采集也一样，大表按行记进度 |
| canvas 表格 | 用画笔画在画布上的表，本质是图片——看得到，读不出文字 |

## 场景覆盖矩阵

| 场景 | 状态 | 关键边界 |
|------|------|----------|
| 原生 `<table>`（含无 thead、表头表体分离、`<td>` 内嵌套子表） | ✅ 完整支持 | XHTML 页面同样兼容 |
| 已登记框架表格（Element UI / Element Plus / Ant Design / Bootstrap Table / Layui / vxe-table / TDesign / Arco） | ✅ | 表头/固定列副本归并为同一张表；同源 iframe 内的框架表也可扫；跨域小窗口里的框架表同样能扫到 |
| div 型行网格（AG Grid / MUI DataGrid / SlickGrid） | ⚠️ 降级 | 已登记 `div-grid` 适配器，能读**当前渲染窗口**的行与样式；读取范围为当前渲染窗口；滚动到目标记录后可再次采集 |
| 其他未登记组件库（Naive UI、Tabulator、Handsontable 等） | ⚠️ 降级 | 底层是原生 `<table>` 的可兜底采集；div 型行、表头分离、固定列克隆形态在适配前采不全。LBI 类绝对定位 div 网格（`.lbi-table`）已单独适配，按自定义网格读取 |
| ARIA Grid / Table | ✅ | 当前页读取 |
| 列表型表格（`ul` / `ol` / `role="list"`） | ✅ | 公告/新闻类列表按表格采集：每个 `li` 一行、行内重复子结构为列；导航、菜单、面包屑、分页器、卡片墙自动排除；列名可按站点自定义、识别严格度可调（严格/标准/宽松）。当前页和手动翻页按同一读取能力接续；列表不自动获得虚拟滚动、加载更多等导航能力 |
| 虚拟滚动表格（纵向） | ⚠️ | **不开自动翻页也能采全当前页**：自动滚动逐屏抓取去重；逐行保留样式与合并信息（已滚出窗口的合并可能补不全） |
| 横向 / 双轴虚拟表格 | ⚠️ | 统一采集链路的条件能力：需要页面显式轴标记与稳定行列身份才启用；普通横向滚动不会误触发。固定列副本与生成列不同名时按列位置投影，不会整行读空 |
| 同源 iframe（任意层级嵌套） | ✅ | 递归不限层级，扫描/读取/翻页/高亮/手动拾取全链路 |
| 跨域 iframe | ⚠️ | 白名单（`.gov.cn` / `.mil.cn` / `.gov`）或设置放开后可用；单帧 8 秒超时按空结果；**帧内表不参与合并**，翻页入口可以在帧内手动点选 |
| 传统「下一页」按钮分页 | ✅ | 默认最大 <Fact product="table-flow" id="limits.autoPaging.maxPages" />，**自本次起始页起算**；触达上限时结尾明说触顶、不假装采全；页码动而内容冻结的"错联分页器"单独归因暂停 |
| 页码序列分页器（只有 1 2 3 … N） | ✅ | 页码 +1 硬校验防静默跳页；三级自愈 |
| Load More / 无限滚动 | ✅ | 按**新增行数**推进、旧行不重复计入；轮数独立于页数预算（单次默认 200 轮，触顶暂停可续采）；终止原因写入采集结果；设置里可整体关闭这类入口 |
| 手动拾取翻页入口 | ✅ | 悬停高亮 + 点击确认；30 秒无操作自动停止；**跨域帧内也可用**（父帧投递、子帧本地拾取） |
| 多级表头与合并单元格 | ✅ | `上级 > 子级` 命名；预览与导出同步还原 |
| 单元格内表单控件 | ✅ | 按可见值采集；密码脱敏、隐藏域不采 |
| 慢加载 / 采集期页面变化 | ✅ | 未加载完即扫描会给风险提示与重扫引导 |
| 结果保留、续采与行级进度 | ✅ | 跨标签页、浏览器重启恢复输出，无需原网页；继续原任务须回原绑定标签核对来源、表格与落页，标签身份变化时输出后新建任务。恢复与输出不重复扣费 |
| 免费翻页开始扣费 | ✅ | 确认开始扣1次，失败、零结果、结束或清理不退还；完整预览无首次交付扣费闸门，同任务继续、切换和重复输出不再扣费；次数以账户为准 |

## 读取、输出与写入范围

**机制限制（浏览器架构决定）**
- canvas 渲染的表格读不出文字。
- 数据没渲染到页面上就采不到；断网时拿不到未加载的数据。
- 宿主页面自己的 Shadow DOM：只有当前可遍历的 open ShadowRoot 内、且有 adapter 支撑的表格才保证；closed、不可遍历、重建后失去稳定定位的不保证。
- 浏览器禁止注入的页面无法工作。

**采集与结果处理**
- 尺寸门槛：iframe 可见尺寸过小（< 200×150）跳过跨域扫描；宽或高为 0 的表格跳过。
- 候选表上限：主文档与同源帧最多 20 张（跨域追加）。表特别多的页面建议先合并收敛。
- 超大虚拟列表：单次采集迭代上限动态估算（默认 200，最高 5000）防死循环；触顶未触底时以已采结果为准并记录本地诊断。
- 虚拟滚动采集逐行保留样式；合并信息按当前结构补，已滚出窗口的合并可能补不全。
- **统计只算已采集快照内的格子**：被拖选排除的格、非数值格、解析歧义的区域写法都不参与；格子算不出来时面板显式写「不可计算」，不用 0 或 `NaN` 占位——统计口径与导出内容同源，不会出现"统计里有、导出里没有"的行。
- **Excel 填充网页只写真实表格行与普通表单里的可写控件**：虚拟/div/ARIA 网格、不可验证的自定义下拉、只读/禁用、混合态复选框、单选/上传控件不支持；双态复选框与完整选项可验证的多选下拉可在表格模式使用；采集可用不代表可写。自动下移只在真实 `<table>` 内进行，自动翻页限顶层文档中可重新定位的真实表格。部分写入失败不回滚、不推进源行；重试会再次触发网页处理——扩展不上传原始文件；既有表格模式不自动提交，逐条新增表单仅执行明确绑定并获准的保存动作，但**网页自己可能因事件自动保存或联网**。
- 旧缓存/模板缺新字段时按旧语义解码，基础导出结构不变。

**产品定案（明确不做）**
- 内网在线模式；离线激活的联网撤销复检；免费翻页额度离线化；旧 RSA 码兼容。
- 注意：离线激活不经服务器登记，平台撤销后**纯离线设备不会感知**。

**选择运行环境**

支持桌面 Chromium 浏览器；安装要求见[安装](/table-flow/install)。大表可先用少量页核对实际行数、导出格式与网站加载方式，再扩大范围。横向虚拟表需稳定行列身份，跨域表格不参与合并；调试控制台 Grid 页签可查看候选表与适配原因。

**任务与结果范围**

新免费翻页任务确认开始扣1次，失败、零结果、结束或清理不退还；已保存结果可完整预览，同任务继续、切换和重复输出不再扣费。尚未结束的任务可继续追加，明确结束后新建任务才再次扣费。跨标签和重启恢复依赖扩展本地数据仍存在；清理本地任务、移除浏览器配置或卸载扩展会影响结果保留。单页免费，在线与离线 Pro 按原授权使用；网页填充翻页仍在批次开始扣费。

## 网页填充的保存边界

逐条新增表单与既有表格逐行填写分别运行。逐条新增可绑定保存与下一条动作；默认逐条人工确认，自动保存须明确允许本批并绑定可靠成功凭据。填写成功不等于平台保存成功，未知结果暂停核对；刷新、取消或重启不会把未决提交当失败自动重试。

当前表单只试填仅支持手动打开记录的一个文本字段，须绑定公开患者与就诊标识；不保存、不换记录、不批量推进。试填前先核对当前记录与字段，按提示确认后操作。

## 手动翻页的页面核对

手动翻页复用原生表、框架表、列表、ARIA、已适配的自定义网格、合并表及可定位 iframe 的读取能力。虚拟表在本页内自动补滚；真实页码或滚动不变的公开页键可区分相邻共享记录页。没有页标时须有唯一关联分页动作和旧页未出现的新记录，不能把滚动窗口变化当新页。短末页可凭网站末页证据封页；列重排/回退/身份不明保护性暂停并保留数据。AG Grid/MUI/SlickGrid 仍限已渲染窗口，未登记的虚拟能力不会因手动模式开放；跨域采集可用不授予跨域填充权限。

运行、暂停和失败时在预览底部「翻页模式」行切换，网页中央弹窗确认后直接执行；转自动时填写后续 `N` 次，不含已确认页；上一次点击仍在进行时先核对实际落页，确认后直接执行。取消或 Escape 保留原模式并暂停。自动段完成即暂停，未完成段继续沿用剩余次数，已完成段继续先填新 `N`。失败保留已确认部分和本页断点，开始扣费待确认沿原请求核对。升级前旧预留任务仅按原协议兼容处理。详见[模式切换教程](/table-flow/quickstart#在自动与手动之间切换)。
