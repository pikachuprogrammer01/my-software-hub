# TableFlow — 网页表格采集与导出

> Chrome / Edge 浏览器扩展（Manifest V3），从网页表格中提取、预览、去重并导出数据。
> 以浮动操作面板形态运行（Shadow DOM 隔离），支持原生表格和主流 UI 框架表格。

**一句话定位**：把网页中已渲染的表格采下来，按自己的节奏翻页、核对并导出；支持的表格形态见[适用范围](/table-flow/scope)。

**它是什么**：轻量级网页表格采集工具，而不只是"表格导出器"。采集、预览、导出默认都在本地完成；最小错误诊断保存在本地内存，扩展网络概览保存在本次浏览器会话存储中，均不自动上传，可主动导出。适合需要频繁从网页取结构化数据、又不想上手爬虫框架的人。选中表格还能直接做数值统计（15 项指标，免费）；另有方向相反的第二条工作流——把本地 Excel 逐行填进网页表单（Excel 填充网页，单页批量填写免费）。

## 采集、核对、交付的一条完整流程

1. **选表与列**：扫描网页，核对高亮并选择需要的列；模板可保存列配置，按域名或 URL 再次应用。
2. **确认开始**：新免费翻页任务此时扣1次，扣费确认后才采页。失败、零结果、结束或清理不退还；实际可用次数见「账户」，不保证固定赠送数量。
3. **按需翻页与切换**：自动执行或手动逐页核对；运行、暂停和失败时都在同一模式行切换。网页中央确认框确认后直接执行，转自动时填写后续次数；取消保留原模式并暂停。自动段完成立即暂停，继续已经完成的段先填新次数。
4. **完整预览与输出**：开始成功后即可查看已保存结果，「显示全部 / 收起」只切换展示范围，没有首次交付扣费闸门。同任务继续、切换和重复输出不再扣费；明确结束后新建任务才再扣1次。
5. **离开后恢复**：「保留的采集任务」支持跨标签页、浏览器重启恢复输出。继续同一任务须回原绑定标签核对来源；原标签已不可用时先输出结果，再新建任务采后续页。

例如确认采集8页公示记录时扣1次，采到第3页可暂停、导出或切手动继续原任务，均不再扣费。失败或清理不退还已经扣除的次数。操作示例见[快速上手](/table-flow/quickstart)。

## 手动翻页与模式切换

手动翻页采集将现有原生、框架、虚拟、列表、ARIA、已登记网格、合并表与 iframe 读取连接到用户亲点网页的流程：插件先读本页，再核验用户触发的新页并累计。无需倒计时或最大页数设置；结构变化或身份不明时暂停保留结果。正常手动等待没有固定时限；运行、暂停和失败时都可从同一行切换，中央弹窗确认后直接执行，取消保留原模式并暂停。后续翻页次数不含已确认页；未完成自动段继续时保留剩余次数，已完成段继续时先输入新的次数。网页填充的手动翻页与待填数据编辑遵循各自目标和源游标边界，详见[使用指南](/table-flow/usage-guide)。
