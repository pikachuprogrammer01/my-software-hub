# TableFlow 隐私政策

**生效日期：2026-09-05**（最近一次校对：2026-11-22——移除续费通知与 Push 登记，保留账户及实际使用时的在线权益核验）
**适用版本：TableFlow v2.1.0**（后续版本如改变处理范围，将另行更新）

TableFlow 是一款用于采集、预览、统计、去重和导出网页表格，以及用本地 Excel 填充网页的浏览器扩展。本政策说明扩展处理哪些信息、为什么处理以及你可以如何控制这些处理。

## 1. 数据处理原则

表格扫描、读取、预览、去重和导出默认在你的浏览器本地完成。扩展不会因为这些功能把表格内容上传到我们的服务器。

为帮助定位问题，扩展在运行期间把运行诊断记录在**扩展本地的内存缓存**中（仅内存，不落盘、不联网）。记录仅在所属运行上下文存活期间存在；你可以在调试控制台**手动点击「导出本地诊断」**生成 JSON 文件，扩展不会自动弹窗、不会自动下载、不会后台上传。该行为没有开关，也不影响扫描、采集、预览、导出或更新功能。

## 2. 本地诊断记录的内容

扩展运行期间，本地诊断（仅内存缓存）可能包含以下最小字段：

- 扩展版本、构建环境、运行上下文和浏览器大版本区间；
- 规范化错误类别、功能名、失败阶段、错误码和有限的结果/重试/耗时区间；
- 脱敏后的静态错误摘要、扩展内部 JavaScript 堆栈帧和一次性诊断 ID；
- 授权故障可能附带设备标识经 SHA-256 后截取的短前缀，用于本地故障归类；不包含原设备码、访问令牌或恢复秘密；
- **业务操作轨迹**（v1.5+）：错误发生前的用户操作序列（如"扫描表格"、"选择列"、"开始
  采集"），用于快速定位问题根源。轨迹仅包含操作/事件名、运行上下文、步骤、函数名、
  一次性流程会话标识与脱敏后的状态计数（如"检测到 3 张表格"、"选择了 5 列"），不包含
  表格内容、列名、网页 URL 或任何用户数据。

记录前使用字段白名单、敏感模式拦截、长度限制和事件大小限制进行过滤；携带禁键的整条事件会被整条拒绝（不进入缓存）。诊断只存在于扩展内存与用户主动导出的文件中，**不会发送到任何第三方服务**。

## 3. 不收集的内容

扩展不会把以下内容写入诊断记录：

- 表格单元格、表头、列名、预览内容、导出文件或模板/规则内容；
- 完整网页 URL、查询参数、iframe 地址、DOM/HTML、截图、网络请求或响应正文；
- Cookie、Authorization、Token、激活码、邮箱、手机号、身份证号、姓名或其他页面输入；
- `chrome.storage` 全量内容、用户账号、广告标识或跨站跟踪标识；
- **业务操作轨迹中的敏感数据**（v1.5+）：字段名命中 `password`/`token`/`secret`/`key`/
  `auth` 等敏感词（精确匹配或作为前后缀词段）的数据会被自动过滤，值匹配邮箱/电话/身份证/
  信用卡等模式的数据也会被过滤。

## 3.1 调试工具的诊断数据（仅本地，默认关闭）

“设置 → 隐私与诊断 → 调试工具”可手动开启采集调试控制台（**默认关闭**，关闭后页面侧相关监听停用）。它提供两类只读取证；扩展后台的请求记录独立于该开关：

- **网络记录**：扩展后台为自身已经发起的 fetch 请求保存有限记录，包括时间、方法、域名（host）、语义归类、状态/结果与耗时；最多 200 条，并按可用容量截断，存于内存与浏览器会话级 `storage.session`，可跨 Service Worker 重启续接，浏览器会话结束后清除。开启调试控制台后还可查看页面已发起请求的本地元数据。这些记录不含完整 URL、路径、查询参数、请求/响应正文与请求头；
- **DOM 快照导出**：把当前页面序列化为单文件 HTML 供本地回放，属于**用户主动导出到本地磁盘**的行为，不向任何服务器上传；导出时会剥离脚本与事件属性，并内联页面自身已加载的样式表。

DOM 快照与上节经过白名单过滤的运行诊断不同，可能包含当前页面可见的业务数据。请自行检查导出文件后再决定是否向他人提供；移除脚本不等于业务内容已匿名化。

上述内容只存在于本地内存、会话存储与用户主动导出的文件中，**不会进入远程诊断链路（扩展无任何错误上报通道）**。后台网络记录可在调试控制台清空；关闭控制台不会停止后台自身的有限请求记录，也不会改变业务联网行为。

## 3.2 激活、许可证与设备标识相关处理

「联网请求超时」仅控制设备注册、恢复、额度与运行权限请求的等待期限（默认15秒、可设1–120整数秒），不增加数据字段或接收方；激活验签与更新检查有独立期限。在线设备码失败按实际原因提示；本机离线申请码与有效 TFOL 导入校验无需在线身份，均在本地完成。

Pro 功能的激活校验是独立的网络请求（只发送激活码本身与**本机设备码**，64 位十六进制标识，不可反推设备信息），具体处理范围以产品激活说明为准；错误诊断不会上传激活码或设备码。**离线激活（TFOL 授权文件）的导入与有效期内授权校验在本地完成**：文件在本地验签并与对应设备标识比对，该校验不上传设备标识、不向服务器登记；因此平台吊销后纯离线设备不会即时感知（换设备或提前吊销需联系开发者重新签发）。授权**到期后本机按免费用户处理**：免费翻页额度走服务端免费通道（设备注册上传 6 项设备特征 + 余额/扣减请求），与本机首次安装时的行为一致——即到期后需要联网才能使用免费翻页额度。安装或更新时可能独立尝试准备在线设备身份，压缩包更新检查也属于独立请求；离线授权不代表整个扩展在所有时刻都不联网。

**设备注册与设备特征字段**：免费额度按设备记账，因此扩展会在**首次安装时**
（以及需要注册或恢复身份时）调用**设备注册接口**（`POST /api/device/register`），
上传下列 **6 项设备特征字段**，由服务器签发本机的**设备码 + 设备令牌**与令牌到期时刻：

| # | 字段 | 说明 |
| --- | --- | --- |
| 1 | 时区 | 如 `Asia/Shanghai` |
| 2 | 浏览器语言 | 如 `zh-CN` |
| 3 | CPU 核心数 | `navigator.hardwareConcurrency` |
| 4 | 操作系统平台 | 如 `Windows` / `macOS` / `Linux` |
| 5 | 屏幕分辨率 | 宽、高拼成**一个字符串**（如 `1920x1080`；**不含色深**） |
| 6 | WebGL 渲染器 | 显卡/驱动暴露的渲染器串 |

- **取不到就传 `null`**：任何一项取不到时传 `null`（不省略、也不填 `""` / `0` / `"unknown"` 之类
  占位值）；**首次注册**需要达到服务端可用字段阈值（默认 6 项中至少 5 项）；已有有效强凭据的恢复独立校验，不因指纹缺项而清除原身份。注册不需要激活码；
  除下方「账号标识的哈希」一节所述的受限读取外，不读取你的账号或邮箱。
- **用途限定**：仅为设备识别与免费额度记账（含反滥用核对）；**不用于广告、用户画像或跨站跟踪，
  不出售、不与任何第三方共享，也不与你的浏览记录或采集到的表格内容关联**。
- **采集频率**：仅在注册及需要刷新设备风险观察时采集，不随每次翻页上报，不用于广告或跨站跟踪。
- **采集方式**：第 1–4 项在扩展后台（service worker）取值；第 5–6 项因扩展后台无页面环境，
  改由扩展**自己的固定采集页**（安装时自动打开的欢迎页）在页面上下文读取、写入扩展本地
  缓存，缓存缺失时可能在冷却窗口后重新打开；注册时由后台读取该缓存——扩展**不会注入你正在浏览的网页**取值；取不到时按上面的
  `null` 规则处理，不会编造值；不新增任何权限。
- **保留期限**：**以服务端在每次注册响应里返回的 `retentionDays` 为准**（源码默认 180 天，
  实际以服务端配置和响应为准），由平台清理任务按该规则处理；客户端不假设、不硬编码任何期限。**IP 地址不以明文长期保留**，
  仅以**加盐哈希**形式用于限流与反滥用判定（哈希不等于匿名化，也不构成不可重新识别的保证）。
- **本地保存**：设备码、设备令牌、独立恢复凭据及其到期时刻保存在扩展本地 `storage.local` 与 `storage.sync`
  （卸载扩展即清除前者；后者可能随 Chrome 账号同步策略保留，可在 Chrome 同步设置中清除）。
  设备令牌是**不透明**串，扩展只原样保存与回传，不解析其内容。
- **完整字段清单**：同见开发仓 `docs/DEVICE_FINGERPRINT_DISCLOSURE.md`（6 项字段、`null` 规则、保留期限与本地保存位置）；
  服务端当前契约（请求 / 响应 / 失败码）见开发仓 `docs/client-integration.md` §14。

**免费额度记账用的标识**：免费翻页额度由授权服务器（`license.pikachu01.me`）记账，
扩展不自行计算。免费额度相关请求（注册/恢复、凭据轮换确认、余额、开始扣费、续租、恢复及原请求对账（旧任务另有预留/结算/释放））按接口发送以下身份和最小操作信息，
不含网页内容、表格数据或邮箱原文：

- **设备码**（64 位小写十六进制）与**设备令牌**（**不透明**串，扩展只做「非空、无空白、长度有界」
  的存储与回带，**不解析内部结构**）与固定功能码 `free_page_turn`；
- **账号标识的哈希**（可选，仅注册及需要刷新设备风险观察时发送）：设备注册时读取当前浏览器**已登录**账号的稳定标识——Chrome 账号，
  或 Edge 的 Microsoft 账户（MSA）/ 云端 Entra ID 账户；优先用账号 id（改邮箱也不变），
  id 为空时才用邮箱。**仅在本地**归一化（去空白；邮箱转小写）后计算 SHA-256，只把这个 64 位
  哈希随注册请求发送。**原始 id / 邮箱永不发送、永不落盘、不进入日志**；服务端只保存该哈希的
  **加盐二次哈希**，观察保留期源码默认 180 天，实际以服务端配置和清理规则为准。哈希只用于反滥用风险判断，不能用于恢复、合并或认领旧账本。未登录（含 Edge 本地部署的 Entra ID
  账户）或未授予权限时不发送该字段，其他能力不受影响。

设备特征与账号哈希只用于风险观察；强凭据用于恢复，其他最小标识用于**免费额度的记账与连续性**，不用于广告、画像或跨站跟踪，不出售、不与任何第三方共享，
也不影响 Pro 激活码的绑定状态。设备通道与激活码通道是两条独立链路，免费额度账本也不同。

**重复赠额核验与复核**：上述已有哈希与同产品的历史首次赠额事实可组合用于判断是否暂缓新赠额。暂缓后建立独立零额度身份，不认领、合并或修改旧账本；账户页「免费额度申请」允许用户主动点「申请赠额」提交复核请求，供管理员核验。请求使用固定申请说明，无需用户输入补充文字；不自动附带网页、表格、账号原文或浏览记录。核验不新增设备字段、权限或更长留存，单一账号/IP 信号不足以单独判定，全部强凭据丢失时也不能保证恢复旧身份。

**独立自动申领核对**：平台记录自动申领首次受理时间、稳定业务标识及其设备账本/赠额机会关联，重放、延期与到账仍属原笔。仅有平台可核验的同一主体绑定时，按 TableFlow 同一额度项目的滚动 7 天第 3 笔生成管理员核对记录；提醒不限制已有额度。当前匿名注册没有这种主体绑定，记为身份未确认，不把账号观察哈希、IP 或指纹相似当成同一人。此流程不新增客户端采集字段或上传网页数据。

### v2.0.3 的恢复凭据与额度对账

恢复原设备账本必须有有效访问令牌或服务端签发的强恢复秘密。设备码、指纹相似度及账号哈希本身均不能取得旧账本。访问令牌通过 Authorization 请求头发送；扩展不会将它写入余额请求的 URL。

授权服务器在自己的域名下通过 Secure/HttpOnly Cookie 保存强恢复凭据，扩展不申请 cookies 权限、不读取其内容，由浏览器自动携带。扩展 local/sync 另保存恢复材料，轮换与确认失败时保留待确认材料供原请求重试。恢复凭据有效期受服务端配置约束（源码默认 730 天，实际以服务端配置及响应为准），不等同于设备特征哈希的观察保留期。清除浏览器 Cookie 与扩展身份副本后，原身份可能无法恢复；账号或指纹不能替代恢复凭据。

额度服务保存最小赠额与消费事实、操作/请求标识、载荷摘要、执行所有权与代际、租约及终态，用于余额核对、避免重复扣费和暂停继续。账本事实的保存周期独立于设备特征哈希的保留期；这些请求不发送网页表格内容或账号原文。

## 3.3 翻页结果的本地保存与交付记账

翻页完整结果保存在扩展独立任务仓库，用于跨面板、标签页与浏览器重启恢复。关闭原网页或常规检查点过期不会删除这些结果。你可以在「保留的采集任务」恢复或清理指定任务；原文删除可在断网时完成，释放请求的最小账务状态另行保留以便联网后核对。

额度服务接收任务、所有权、请求、代次、采集意图摘要与必要状态，用于任务开始扣费、续租、恢复及幂等对账；旧任务仍保留原结果摘要与预留/结算/释放兼容。新任务摘要绑定固定启动意图，**不上传表格内容、表头、原网页地址或导出文件**。消费事实保存于服务端账本，同一任务继续、切换方式、查看、导出或复制不重复扣费；失败、零结果和删除本地原文不退还已扣次数。

## 4. 诊断数据的保存与删除

运行诊断事件只保存在扩展本地的内存缓存中（有界容量，FIFO 淘汰最旧），所属上下文结束或 Service Worker 重启后丢弃。§3.1 的后台网络记录另使用 `storage.session` 跨后台重启续接，清空记录或浏览器会话结束后清除。两者**均没有远程诊断服务器副本或第三方处理方**。需要长期留存时，由你手动导出文件并自行保管；导出后的删除由你删除该文件完成。

扩展本身不会建立用户账号，也不会出售诊断数据。

## 5. 权限用途

- `storage`：保存设置、采集缓存、模板、授权/设备身份材料、最小执行日志和调试开关；后台有限网络记录使用会话存储；
- `scripting`、`activeTab`、`tabs`：在用户操作的标签页中注入面板、读取表格、按用户选择填充字段并完成跨上下文通信；注册打包的固定 MAIN helper。设备注册需要的屏幕分辨率与 WebGL 渲染器**不**由这些权限采集，而由扩展**自己的固定采集页**读取（MV3 后台无页面环境，见 §3.2），不注入用户正在浏览的网页；
- `identity`、`identity.email`：仅用于注册及需要刷新设备风险观察时读取当前**已登录**浏览器账号的稳定标识（Chrome 账号 / Edge 的 MSA 或云端 Entra ID），在本地计算 SHA-256 后作为可选字段随注册请求发送，用于免费额度反滥用风险判断，不能作为恢复凭据；原始 id / 邮箱不出网、不落盘、不进日志；未登录或未授权时自动降级，不读取、不发送；
- `<all_urls>`：支持在不同网站及 iframe 中扫描表格，并由 Background 发起更新检查与固定的许可证请求；调试控制台的样式代理也经 Background 取回页面自身已加载的样式表（仅用于本地快照回放，不上传）。

扩展不通过远程脚本加载或执行代码。压缩包渠道的更新检查会访问固定的 Gitee 更新清单；下载链接由用户点击打开。商店安装的更新由浏览器和商店管理。设备/授权请求、用户打开的文档与下载页面及调试样式取回均不属于错误诊断上传。

扩展不申请 `cookies` 权限，不通过 Cookie API 读取、解析或修改 Cookie 的内容；自有授权服务器通过 HTTP 响应设置其域下的恢复 Cookie，由浏览器自动保存和携带。

## Excel 网页填充与逐条新增表单

Excel 仅在当前宿主文档内存解析，不执行宏或公式，不上传原始工作簿。字段写入和用户允许的保存动作会触发目标网站自己的校验、保存或网络请求，目标网站会接收填入的业务字段。

表格模板 v1 使用扩展 sync，只存映射配置；表单模板 v2 仅在本机 local 保存字段、规则、条件、定位和动作配置。固定值默认不保存，用户可逐字段明确选择包含，包含的固定值可能含业务信息。模板不保存工作簿数据行、下拉选项、DOM、运行位置、成功结论或每批自动保存许可。

为防止重复提交，后台在 local 保存最小执行日志：不透明运行/记录/尝试身份、源文件内容摘要与范围身份、计划版本及摘要、目标范围摘要、记录序号、执行所有权代次、阶段/结果/时间与累计计数。日志不包含单元格值、DOM、选项、Cookie 或业务响应正文，不发送到远端。刷新或重启不把未决提交当失败自动重试；取消仍保留未决线索，文件摘要只用于一致性校验，不证明业务记录已保存。

## 在线续费核验与通知边界

管理员续费后，扩展在进入账户或实际使用在线 Pro 功能时，沿既有授权接口以当前强设备身份及实际绑定核验权益。账户倒计时在本地更新，空闲和隐藏页面不为刷新日期循环联网；本地离线授权不因此新增联网依赖。

扩展不申请浏览器通知权限、不获取 VAPID 公钥、不登记 Push 订阅，也不通过续费 Push 唤醒后台。升级时仅通过浏览器已有能力尽力退役旧订阅并清理本地通知设置，不为此取得新身份或调用 Hub 注册、注销接口；失败保持停用。客户端移除不代表服务端历史订阅、事件或投递记录已经删除，这些记录仍按服务端既有数据管理流程处理。诊断仍不自动上传。
