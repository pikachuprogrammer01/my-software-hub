# TableFlow 隐私政策

**生效日期：2026-09-05**（最近一次校对：2026-09-24，补充本地网络取证与离线激活口径）  
**适用版本：TableFlow v1.6.0（已发布）及后续版本**

TableFlow 是一款用于扫描、预览、去重和导出网页表格的浏览器扩展。本政策说明扩展处理哪些信息、为什么处理以及你可以如何控制这些处理。

## 1. 数据处理原则

表格扫描、读取、预览、去重和导出默认在你的浏览器本地完成。扩展不会因为这些功能把表格内容上传到我们的服务器。

为帮助定位问题，扩展在运行期间把运行诊断记录在**扩展本地的内存缓存**中（仅内存，不落盘、不联网）。这些记录只在扩展休眠或浏览器关闭前存在；你可以在调试控制台**手动点击「导出本地诊断」**生成 JSON 文件，扩展不会自动弹窗、不会自动下载、不会后台上传。该行为没有开关，也不影响扫描、采集、预览、导出或更新功能。

## 2. 本地诊断记录的内容

扩展运行期间，本地诊断（仅内存缓存）可能包含以下最小字段：

- 扩展版本、构建环境、运行上下文和浏览器大版本区间；
- 规范化错误类别、功能名、失败阶段、错误码和有限的结果/重试/耗时区间；
- 脱敏后的静态错误摘要、扩展内部 JavaScript 堆栈帧和一次性诊断 ID；
- **业务操作轨迹**（v1.5+）：错误发生前的用户操作序列（如"扫描表格"、"选择列"、"开始
  采集"），用于快速定位问题根源。轨迹仅包含操作/事件名、运行上下文、步骤、函数名、
  一次性流程会话标识与脱敏后的状态计数（如"检测到 3 张表格"、"选择了 5 列"），不包含
  表格内容、列名、网页 URL 或任何用户数据。

记录前使用字段白名单、敏感模式拦截、长度限制和事件大小限制进行过滤；携带禁键的整条事件会被整条拒绝（不进入缓存）。诊断只存在于扩展内存与用户主动导出的文件中，**不会发送到任何第三方服务**。

## 3. 不收集的内容

扩展不会把以下内容写入诊断记录：

- 表格单元格、表头、列名、预览内容、导出文件或模板/规则内容；
- 完整网页 URL、查询参数、iframe 地址、DOM/HTML、截图、网络请求或响应正文；
- Cookie、Authorization、Token、激活码、邮箱、手机号、身份证号、姓名或其他页面输入；
- `chrome.storage` 全量内容、用户账号、广告标识或跨站跟踪标识；
- **业务操作轨迹中的敏感数据**（v1.5+）：字段名命中 `password`/`token`/`secret`/`key`/
  `auth` 等敏感词（精确匹配或作为前后缀词段）的数据会被自动过滤，值匹配邮箱/电话/身份证/
  信用卡等模式的数据也会被过滤。

## 3.1 调试工具的诊断数据（仅本地，默认关闭）

v1.6 起，“设置 → 调试工具”可手动开启采集调试控制台（**默认关闭**，关闭后相关监听全部停用）。它提供两类只读取证：

- **网络记录**：展示扩展自身与目标页面已发起的请求的**域名（host）、语义归类、状态与耗时**；不记录完整 URL、路径、查询参数、请求/响应正文与请求头；
- **DOM 快照导出**：把当前页面序列化为单文件 HTML 供本地回放，属于**用户主动导出到本地磁盘**的行为，不向任何服务器上传；导出时会剥离脚本与事件属性，并内联页面自身已加载的样式表。

上述内容只存在于本地内存与用户主动导出的文件中，**不会进入远程诊断链路（扩展无任何错误上报通道）**。

## 3.2 激活与许可证相关处理

Pro 功能的激活校验是独立的网络请求（发送激活码本身与设备指纹 ID，不发送指纹原始维度），具体处理范围以产品激活说明为准；错误诊断不会上传激活码或设备指纹。**离线激活（v1.6，TFOL 授权文件）全程零网络请求**：文件在本地验签并与设备指纹比对，不上传指纹、不向服务器登记；因此平台吊销后纯离线设备不会即时感知（换设备或提前吊销需联系开发者重新签发）。

## 4. 诊断数据的保存与删除

诊断只保存在扩展本地的内存缓存中（有界容量，FIFO 淘汰最旧），扩展休眠、浏览器关闭或 Service Worker 重启后即丢弃，**不存在服务器端副本、保留期限或第三方处理方**。需要长期留存时，由你在调试控制台手动导出 JSON 文件并自行保管；删除同样由你删除该文件完成。

扩展本身不会建立用户账号，也不会出售诊断数据。

## 5. 权限用途

- `storage`：保存本地设置、采集缓存和用户的调试控制台开关；
- `scripting`、`activeTab`、`tabs`：在用户操作的标签页中注入面板、读取表格并完成跨上下文通信；
- `<all_urls>`：支持在不同网站及 iframe 中扫描表格，并由 Background 发起更新检查与固定的许可证请求；调试控制台的样式代理也经 Background 取回页面自身已加载的样式表（仅用于本地快照回放，不上传）。

扩展不通过远程脚本加载或执行代码。
