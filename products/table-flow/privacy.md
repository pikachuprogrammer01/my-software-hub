# TableFlow 隐私政策

**生效日期：2026-09-05**（最近一次校对：2026-10-15——设备特征字段收敛为 **6 项**，屏幕分辨率与 WebGL 渲染器改由安装时自动打开的固定采集页读取，并补充 Chrome 账号标识哈希的披露）  
**适用版本：TableFlow v2.0.0 及后续版本**

TableFlow 是一款用于扫描、预览、去重和导出网页表格的浏览器扩展。本政策说明扩展处理哪些信息、为什么处理以及你可以如何控制这些处理。

## 1. 数据处理原则

表格扫描、读取、预览、去重和导出默认在你的浏览器本地完成。扩展不会因为这些功能把表格内容上传到我们的服务器。

为帮助定位问题，扩展在运行期间把运行诊断记录在**扩展本地的内存缓存**中（仅内存，不落盘、不联网）。这些记录只在扩展休眠或浏览器关闭前存在；你可以在调试控制台**手动点击「导出本地诊断」**生成 JSON 文件，扩展不会自动弹窗、不会自动下载、不会后台上传。该行为没有开关，也不影响扫描、采集、预览、导出或更新功能。

## 2. 本地诊断记录的内容

扩展运行期间，本地诊断（仅内存缓存）可能包含以下最小字段：

- 扩展版本、构建环境、运行上下文和浏览器大版本区间；
- 规范化错误类别、功能名、失败阶段、错误码和有限的结果/重试/耗时区间；
- 脱敏后的静态错误摘要、扩展内部 JavaScript 堆栈帧和一次性诊断 ID；
- **业务操作轨迹**（v1.5+）：错误发生前的用户操作序列（如"扫描表格"、"选择列"、"开始
  采集"），用于快速定位问题根源。轨迹仅包含操作/事件名、运行上下文、步骤、函数名、
  一次性流程会话标识与脱敏后的状态计数（如"检测到 3 张表格"、"选择了 5 列"），不包含
  表格内容、列名、网页 URL 或任何用户数据。

记录前使用字段白名单、敏感模式拦截、长度限制和事件大小限制进行过滤；携带禁键的整条事件会被整条拒绝（不进入缓存）。诊断只存在于扩展内存与用户主动导出的文件中，**不会发送到任何第三方服务**。

## 3. 不收集的内容

扩展不会把以下内容写入诊断记录：

- 表格单元格、表头、列名、预览内容、导出文件或模板/规则内容；
- 完整网页 URL、查询参数、iframe 地址、DOM/HTML、截图、网络请求或响应正文；
- Cookie、Authorization、Token、激活码、邮箱、手机号、身份证号、姓名或其他页面输入；
- `chrome.storage` 全量内容、用户账号、广告标识或跨站跟踪标识；
- **业务操作轨迹中的敏感数据**（v1.5+）：字段名命中 `password`/`token`/`secret`/`key`/
  `auth` 等敏感词（精确匹配或作为前后缀词段）的数据会被自动过滤，值匹配邮箱/电话/身份证/
  信用卡等模式的数据也会被过滤。

## 3.1 调试工具的诊断数据（仅本地，默认关闭）

v1.6 起，“设置 → 调试工具”可手动开启采集调试控制台（**默认关闭**，关闭后相关监听全部停用）。它提供两类只读取证：

- **网络记录**：展示扩展自身与目标页面已发起的请求的**域名（host）、语义归类、状态与耗时**；不记录完整 URL、路径、查询参数、请求/响应正文与请求头；
- **DOM 快照导出**：把当前页面序列化为单文件 HTML 供本地回放，属于**用户主动导出到本地磁盘**的行为，不向任何服务器上传；导出时会剥离脚本与事件属性，并内联页面自身已加载的样式表。

上述内容只存在于本地内存与用户主动导出的文件中，**不会进入远程诊断链路（扩展无任何错误上报通道）**。

## 3.2 激活、许可证与设备标识相关处理

Pro 功能的激活校验是独立的网络请求（只发送激活码本身与**本机设备码**，64 位十六进制标识，不可反推设备信息），具体处理范围以产品激活说明为准；错误诊断不会上传激活码或设备码。**离线激活（v1.6，TFOL 授权文件）在授权有效期内全程零网络请求**：文件在本地验签并与设备码比对，不上传设备码、不向服务器登记；因此平台吊销后纯离线设备不会即时感知（换设备或提前吊销需联系开发者重新签发）。授权**到期后本机按免费用户处理**：免费翻页额度走服务端免费通道（设备注册上传 6 项设备特征 + 余额/扣减请求），与本机首次安装时的行为一致——即到期后需要联网才能使用免费翻页额度。

**设备注册与设备特征字段**：免费额度按设备记账，因此扩展会在**首次安装时**
（以及本机设备身份丢失、令牌到期时）调用一次**设备注册接口**（`POST /api/device/register`），
上传下列 **6 项设备特征字段**，由服务器签发本机的**设备码 + 设备令牌**与令牌到期时刻：

| # | 字段 | 说明 |
| --- | --- | --- |
| 1 | 时区 | 如 `Asia/Shanghai` |
| 2 | 浏览器语言 | 如 `zh-CN` |
| 3 | CPU 核心数 | `navigator.hardwareConcurrency` |
| 4 | 操作系统平台 | 如 `Windows` / `macOS` / `Linux` |
| 5 | 屏幕分辨率 | 宽、高拼成**一个字符串**（如 `1920x1080`；**不含色深**） |
| 6 | WebGL 渲染器 | 显卡/驱动暴露的渲染器串 |

- **取不到就传 `null`**：任何一项取不到时传 `null`（不省略、也不填 `""` / `0` / `"unknown"` 之类
  占位值）；**6 项里至少 5 项可用**才允许注册（阈值默认 5，由服务端配置）。注册不需要激活码，
  也不读取你的账号或邮箱。
- **用途限定**：仅为设备识别与免费额度记账（含反滥用核对）；**不用于广告、用户画像或跨站跟踪，
  不出售、不与任何第三方共享，也不与你的浏览记录或采集到的表格内容关联**。
- **采集频率**：只在注册那一刻采集**一次**，不持续采集，也不用于注册之外的任何上报；
  注册完成后这些字段不会再上传。
- **采集方式**：第 1–4 项在扩展后台（service worker）取值；第 5–6 项因扩展后台无页面环境，
  改由扩展**自己的固定采集页**（安装时自动打开的欢迎页）在页面上下文读取一次、写入扩展本地
  缓存，注册时由后台读取该缓存——扩展**不会注入你正在浏览的网页**取值；取不到时按上面的
  `null` 规则处理，不会编造值；不新增任何权限。
- **保留期限**：**以服务端在每次注册响应里返回的 `retentionDays` 为准**（默认 180 天，
  服务端可配置），到期由平台清理；客户端不假设、不硬编码任何期限。**IP 地址不以明文长期保留**，
  仅以**加盐哈希**形式用于限流与反滥用判定（可核对、不可反查）。
- **本地保存**：设备码、设备令牌与令牌到期时刻保存在扩展本地 `storage.local` 与 `storage.sync`
  （卸载扩展即清除前者；后者可能随 Chrome 账号同步策略保留，可在 Chrome 同步设置中清除）。
  设备令牌是**不透明**串，扩展只原样保存与回传，不解析其内容。
- **完整字段清单**：同见开发仓 `docs/DEVICE_FINGERPRINT_DISCLOSURE.md`（6 项字段、`null` 规则、保留期限与本地保存位置）；
  服务端契约（请求 / 响应 / 失败码）见开发仓 `docs/client-integration.md` §13。

**免费额度记账用的标识**：免费翻页额度由授权服务器（`license.pikachu01.me`）记账，
扩展不自行计算。额度相关的请求里扩展发送的只有以下标识，不含网页内容、表格数据或邮箱原文：

- **设备码**（64 位小写十六进制）与**设备令牌**（**不透明**串，扩展只做「非空、无空白、长度有界」
  的存储与回带，**不解析内部结构**）与固定功能码 `free_page_turn`；
- **账号标识的哈希**：扩展读取当前 Chrome 账号的邮箱地址，**仅在本地**做归一化（去空白、转小写）后
  计算 SHA-256 哈希，只把这个 64 位哈希值发给授权服务器。**原始邮箱地址永不发送、永不落盘、不进入
  日志**；哈希不可逆推邮箱，仅用于让同一 Chrome 账号下的免费额度保持连续。未登录 Chrome 或未授权时
  不发送该字段，其他能力不受影响。

这些标识只用于**免费额度的记账与连续性**，不用于广告、画像或跨站跟踪，不出售、不与任何第三方共享，
也不影响 Pro 激活码的绑定状态。设备通道与激活码通道是两条独立链路，免费额度账本也不同。

## 4. 诊断数据的保存与删除

诊断只保存在扩展本地的内存缓存中（有界容量，FIFO 淘汰最旧），扩展休眠、浏览器关闭或 Service Worker 重启后即丢弃，**不存在服务器端副本、保留期限或第三方处理方**。需要长期留存时，由你在调试控制台手动导出 JSON 文件并自行保管；删除同样由你删除该文件完成。

扩展本身不会建立用户账号，也不会出售诊断数据。

## 5. 权限用途

- `storage`：保存本地设置、采集缓存和用户的调试控制台开关；
- `scripting`、`activeTab`、`tabs`：在用户操作的标签页中注入面板、读取表格并完成跨上下文通信。设备注册需要的屏幕分辨率与 WebGL 渲染器**不**由这些权限采集，而由扩展**自己的固定采集页**（安装时自动打开的欢迎页）读取一次（MV3 后台无页面环境，见 §3.2），不注入用户正在浏览的网页；
- `identity`、`identity.email`：读取当前 Chrome 账号的邮箱地址，**仅在本地**计算 SHA-256 哈希后随免费额度请求发送，用于让同一账号下的免费额度保持连续（原始邮箱不出网、不落盘、不进日志，见 §3.2）；未登录 Chrome 或未授权时自动降级为不发送该字段，不影响其他任何能力；
- `<all_urls>`：支持在不同网站及 iframe 中扫描表格，并由 Background 发起更新检查与固定的许可证请求；调试控制台的样式代理也经 Background 取回页面自身已加载的样式表（仅用于本地快照回放，不上传）。

扩展不通过远程脚本加载或执行代码。

扩展不申请 `cookies` 权限，不读取、不解析、也不修改任何 Cookie 的内容。
