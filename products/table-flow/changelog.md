## v2.0.1 — 统一表格接入架构与调试台 Grid 画像

> 官方更新说明偏工程口径；下面把同一批变化翻成用户视角（取自开发仓工程台账里**用户可感知**的部分）。

**变更 · 表格识别统一到一条接入链**

原生 `<table>`、已登记框架（Element UI / Element Plus / Ant Design / Bootstrap Table / Layui）、ARIA Grid/Table、`ul`/`ol` 列表与 LBI 类绝对定位 div 网格，现在共用同一条「识别 → 会话 → 读取」链，差异只留在各自的适配器里。

- **对你意味着**：同一张表在采集、预览、统计、导出与网页填充里读到的是同一份数据形状，不再出现"这里能采、那里算不出来"的分叉。
- 旧的虚拟读取兜底路径与内部开关已删除（操作方式无变化）。

**新增 · 调试控制台 Grid 页签（排障用，默认关闭）**

- **候选根列表**：列出当前页可能成为表格根的节点（`table` / `role=grid` / `.el-table` / `.lbi-table` / 列表根等），每条显示选择器、适配器、列数与行数；未识别的会直接写明拒绝原因（`no-registered-adapter`）。已登记框架内部的 `<table>` 会被跳过，不会把内部结构误当独立表。
- **任意 selector 现场画像**：输入框里填任意 CSS 选择器即可画像，未登记的 div 网格也能看结构。
- **spec 草稿**：选中根后生成保守的 GridSpec 草稿（含置信度与假设清单），可一键复制；也可导出 `{ 选中画像, 全部候选, 扫描 trace }` 的 Grid JSON，适合附在反馈里。
- 调试报告 JSON 新增 `grid` 段；表级 DOM 快照同样附带 Grid 画像。
- 它是**只读工具**：不注册采集会话、不修改页面 DOM、不触发采集。

**修复**

- 横向虚拟表（固定列副本的视觉列键与生成列 ID 不同名）整行读成空值。
- iframe 内表格重载后，第 2 页被读成第 1 页：会话元素来自已导航离开的旧文档时先重找，找不到就返回空值走重试。
- DOM 快照覆盖扩展到列表、ARIA、自定义网格与已脱离文档的表；页面快照支持同源 iframe/frame、`template` 与 open shadow root，跨域与 closed shadow 会明确标注限制。
- `?tfdebug=1` 在登记表为空时先重扫再捕获，不再直接报「元素不可用」。

## v2.0.0 — Excel 填充网页与表格统计

**新增 · Excel 填充网页（第二条工作流）**

把本地 Excel 的每一行按顺序填进网页表单，适合 ERP 单据起草、订单/库存录入这类重复录入。扩展不会替你点「提交」。

- **单页批量填写免费**：不激活也能用；只有开启自动翻页时才消耗与采集共享的那份免费额度。
- **四步改为**：选择表格（开始/结束列、开始/结束行、表头行五项输入）→ 设置填充行列 → 检查映射 → 批量填充。
- **行 / 列 / 字段三种选择**：行模式点一行里任意可填位置就选中该行全部字段；**同一列选多行会自动识别为「行 × 列」区域**，第 N 条 Excel 记录写第 N 行，不会串列。
- **对照表**：检查映射时最多展示前 10 行 × 前 10 列的 Excel 值与网页原值并列对照，停止原因会具体到行号（如「第 3 条网页行的列数或合并结构与上一条不同」）。
- **映射可设为「None（不填充）」**：没有可写控件的目标自动跳过，不会因此挡住整张映射。
- **批量与翻页**：点「开始批量填充」自动逐行写入，可暂停/继续/取消；填完一轮后重选目标会自动回到 Excel 第 1 行。
- **填充模板为 Pro**：免费用户在成功填完一行后会看到带锁的升级说明。

**新增 · 表格统计（免费）**

- 选中表格即可算 15 项数值指标，默认启用基础 6 项，其余可在设置里勾选。
- 整体 / 按列 / 按行三档范围，可在结果快照上拖选纳入或排除。
- 算不出来的格子显式标注「不可计算」并给原因，不用 0 或 `NaN` 占位。
- 大表统计在后台计算，界面不卡顿；统计结果可作为独立区块并入 Excel / CSV 导出。

**变更**

- **默认授予的采集流程次数由 3 次提高**，实际余额以平台为准；平台重置或追加授予后会自动恢复。
- **免费翻页额度跨卸载重装保持**：免费额度改为由服务端按设备记账，卸载重装不再重置。
- 离线授权文件到期后，本机回落为免费用户，免费翻页改走服务端免费通道（需要联网）。
- 翻页预算改为**自本次起始页起算**。

**修复**

- 一次导入文本方言的 `.xls`（老 ERP 常见）后，后续导入正常 `.xlsx`/`.xlsm` 误报「无法解析该文件」。
- 网页填充批次可能卡在「正在批量填充…」：目标失效时不再一直转圈，改为暂停并给出提示。
- 在线激活码分组符号被误删导致恒报「激活码未登记」的同类问题已彻底修复（照订阅时收到的样子粘贴即可）。

## v1.6.1 — 在线激活修复与免费额度加固（已发布 2026-09-26）

官方更新说明只写了一句「**修复在线激活码提示『未登记/激活码无效』**」。下面是该版本里用户同样能感知的其余变化（取自开发仓工程台账的用户可感知部分）。

**修复**

- **在线激活报「激活码未登记」（404）**：复制粘贴的激活码里分组符号被客户端误删导致校验对不上。现在激活码按你粘贴的原文透传——**照订阅时收到的样子粘贴即可，不需要手动改动**。旧版本扩展由平台侧兼容处理，无需重装即可激活。
- **免费翻页额度不再能靠"卸载重装"刷新**：此前反复卸载重装可以绕过 3 次限制。现在免费额度由服务端统一记账，只有实际消费才计数。
  - **带来的行为变化（如实说明）**：完全断网、且未持有 Pro/离线授权的免费用户，翻页流程会被明确拒绝并提示「请联网或升级 Pro」，不再像过去那样离线也能先跑一次。持有离线授权的用户不受影响，仍为零网络请求。

**体验**

- **订阅页按激活状态显示**：本机已是 Pro（含离线授权）时收起激活码输入表单，只显示「当前设备已是 Pro 版本，无需再次激活」；解绑、过期或被服务端否决后输入框自动重新开放。激活成功/失败的反馈不再被折叠隐藏。

**🔬 实验中（默认关闭，尚未计入正式能力）**

- 多表批量导出（多 Sheet Excel / 多数据集 JSON）、无限滚动页面采集、横向与双轴虚拟表格、单元格语义读取（链接/图片/附件/控件）、多表串行采集、Generic CSS Grid 识别探针——均只在实验开关或旁路里可用，默认不改变现有采集与导出行为。

## v1.6.0 — 完全离线激活

- **离线激活（Pro 专属）**：面向完全断网环境。凭设备码申请离线授权文件，本地校验即激活，**全程零网络请求**；一份文件绑定一台设备，有效期为时间盒。
- **页码序列翻页**：只有 `1 2 3 … N`、没有「下一页」按钮的页面也能自动翻页；与下一页按钮并存时可自动切换，也可在设置里指定优先级。
- **单元格表单所见即所得**：输入框、下拉框按你在页面上看到的当前值采集（含只读、禁用态）。
- **调试控制台网络取证**：排障时可查看请求证据。
- **修复**：免费翻页额度显示与实际不一致；偏好设置保存失败；合并去重默认档位不符预期。
- **稳定性**：翻页采集提速，存储写入更稳。
