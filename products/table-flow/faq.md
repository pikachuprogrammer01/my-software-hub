# 常见问题

先按问题找答案；需要连续操作与示例时，见[快速上手](/table-flow/quickstart)和[完整使用手册](/table-flow/usage-guide)。

## 翻页额度、交付与恢复

**Q：一开始翻页就会扣一次吗？**

A：是。新免费翻页任务确认开始即扣1次，扣费确认后才采页；失败、零条有效结果、主动结束和清理都不退还。同一任务暂停继续、切换自动或手动、重复查看和输出不再扣费。单页免费，在线 Pro 与离线 Pro 按原授权使用；网页填充翻页仍在批次开始扣费。

**Q：总行数一直增加，预览为什么只有几行？**

A：先核对总页数和总行数，再点「显示全部 … 行」。新任务开始已扣费，「显示全部 / 收起」只调整展示范围，不设首次交付样例闸门，也不再收一次额度。

**Q：先完整预览，再导出 Excel 和 CSV，会算三次吗？**

A：不会。已确认开始的同一任务反复预览、导出或复制都不再扣费；保存取消或文件生成失败后可以重试输出，已扣次数不退款。

**Q：已经导出的结果还能继续追加下一页吗？**

A：尚未结束的任务可以暂停后继续或切换方式接续，不再扣费。只有明确「结束采集」后结果定稿，追加页面才需新建任务并再扣1次。

**Q：手动翻页等五分钟会停吗？**

A：正常等待手动翻页没有固定时限。明确暂停后保留已确认页与断点，继续原任务不重扣。联网确认失败需按提示核对并恢复；新任务不按暂停时长释放或退回已经扣除的次数。

**Q：反复点暂停或重新查询会退回额度吗？**

A：不会。开始成功即形成扣费事实，暂停、关闭、结束、零结果和清理均不退款。升级前的旧预留任务仅按原协议兼容核对，请保留原任务和原请求，不把它当新任务重建。

**Q：手动转自动填 3 页，是总共 3 页吗？**

A：切换确认框的「接下来自动翻几页？」填写后续翻页次数，不含已采页。已确认网站第6页后填 `3`，接着采第7～9页，本段结束即暂停并保留预览。首次自动任务的「最大采集页数」包含起始页；继续未完成段保留剩余次数，继续已经完成的段先输入新的 `N`。

**Q：切换模式时提示“正在确认上一页操作”，要再点网页下一页吗？**

A：从预览底部同一行「翻页模式」操作，运行、暂停或失败时都可切换；中央确认框立即出现，转自动时可马上填写次数。系统先核对实际落页并保存，完成前确认不可用、仍可取消。确认后直接执行，无需再点继续；不要重复点击网页下一页。取消或 Escape 保留原模式与数据并保持暂停，继续原模式再点「继续」。

**Q：翻页坏了，还能导出前面采到的内容吗？**

A：可以。失败会暂停并解除操作阻塞，已确认页保留。可在同一模式行切手动，或重选入口并核对落页后恢复；无法继续时结束采集并输出已确认部分，未完成草稿按提示处理。失败或没有有效结果都不退还已扣次数，输出与同任务恢复不再扣费。

**Q：关闭原标签页、重启浏览器后还能拿到结果吗？**

A：在可打开面板的网页找到「保留的采集任务」，点「恢复结果」即可查看和输出，不需要原网页仍在。继续原任务需回到原绑定标签并核对来源、表格与落页；原标签关闭或重启后身份变化时，先输出原结果，再新建任务采后续页。保留该浏览器配置与扩展本地数据，不要为恢复而卸载或清空配置。

**Q：开始扣费超时，是否应该重新采一次？**

A：保留原任务与配置，联网后重试原开始操作。系统先核对原任务和原请求，已成功扣费则恢复，不换号重复扣；无法确认时暂停，不先采集。旧任务若提示结算待确认，仍沿原请求核对。

**Q：断网时能清除采集数据吗？**

A：可以。当前任务先暂停，在底部「任务操作」选「清理本次任务数据…」；历史任务在「保留的采集任务」中点对应条目的「清理此任务数据…」。核对确认框中的来源、行数和不可恢复提示，再点「清理本地数据」。断网可删除本地原文，已扣次数不退还；清理后不能恢复或继续任务，请先导出。仅本地删除未完成时按提示点「重试本地清理」，旧任务账务兼容由系统处理。

## 操作、识别与导出

**Q：新版设置、订阅和账户入口在哪里？**

A：浮动面板点「升级 Pro」或「Pro」打开独立管理页，默认「账户」；顶部切「订阅」或「设置」。设置分类在宽窗口左侧、窄窗口上方；先选分类，再选页内标签。默认翻页页数和联网超时在「表格采集 → 翻页与等待」，下拉策略在「网页填充 → 字段与取值」。完整位置见[入口速查](/table-flow/quickstart#新界面里从哪里打开设置)。

**Q：手动翻页采集和“手动选择”有什么区别？**

A：「手动翻页采集」是列配置底部的独立按钮，插件先采本页，再等你在网页或面板点下一页。「手动选择」是连续翻页的入口拾取，选定后仍由插件连续点击分页器。

**Q：出现“疑似重复领取，等待人工复核”怎么办？**

A：在「账户 → 免费额度申请」点「申请赠额」复核原本尚未到账的机会，再点「刷新赠额状态」查询。没有原机会时按实际提示处理，不会新建无限赠额申请；额外额度联系开发者，由管理员后台直接调整。保留当前身份；重装、清 Cookie 不会推进审核，审批通过与实际到账分别显示，以账户余额为准。

**Q：表格没有被识别出来？**

A：点击「刷新」按钮重新扫描。确认表格不是通过 JavaScript 延迟渲染的（等待页面加载完成后再试）。某些复杂框架表格可能需要等待框架组件完全渲染。页面是 `ul/li` 列表的话，确认设置页「表格采集 → 识别范围 → 列表识别（ul/li）」已开启；仍不出现时可把「列表识别严格度」放宽到「宽松」再重扫（默认「标准」与历史行为一致）。

**Q：列表采集出来了，但列名是「列1」「列2」？**

A：说明这个列表既没有页面自己的列名声明，也没有命中内置规则。到设置页「模板与规则 → 列名规则」加一条：点「+ 新增规则」，在「我要识别什么？」里选「日期」「标题链接」这类现成选项（选完条件就自动填好了），填一个列名保存即可，重扫后按你的名字显示。

**Q：导出的手机号变成科学计数法了？**

A：使用 Excel (.xlsx) 格式导出会自动处理此问题。如果使用 CSV 格式，在 Excel 中打开后请将单元格格式设为「文本」再粘贴。

**Q：翻页采集没有自动翻页？**

A：尝试手动选择翻页入口：在「配置列」中选择「翻页采集 → 手动选择」，点击「去页面选择」，再点击网页上的下一页按钮或页码数字。框架类网站可能需要手动选择；表格在别家网站的小窗口里时，也可以直接在小窗口内点选翻页按钮。

**Q：表格只采到看得见的那几行（虚拟列表）？**

A：卡片带「虚拟列表」徽标的表，采集时会自动滚动逐屏补回未渲染的行，**这一步不需要开启自动翻页**。没有徽标却只采到几行，说明该页面的虚拟形态还没被判定命中（常见于尚未适配的组件库），此时只会拿到页面上已渲染的行且不报缺行——请与页面行数核对后展开或重新扫描。

**Q：表格结构比较特殊（div 拼的网格），怎么知道它为什么没被识别？**

A：在「设置 → 隐私与诊断 → 调试工具」开启「采集调试控制台」，再点面板头部「调试」，选 **Grid** 页签：上半部列出当前页所有候选表根（含适配器、列数/行数，未识别的会直接写 `no-registered-adapter`），工具栏输入框里填任意 CSS 选择器也能现场画像；选中根后能看到适配器、能力、证据与定位，并可一键复制 GridSpec 草稿或导出 Grid JSON。这份 JSON 直接附在反馈里，比截图更能说明问题。它是只读工具——不注册采集会话、不改页面 DOM、不触发采集。

**Q：页面底部是「加载更多」，能一次点到底吗？**

A：能。入口会被自动识别（也可在「手动选择」里点选它），采集按「新增行数」推进：每点一轮只把新长出来的行计入，旧行不会重复；按钮消失/禁用、或连续 2 轮点击都没有新行时按数据末尾自动停止，终止原因会写进采集结果提示。采集轮数与翻页页数相互独立，默认单次最多 200 轮，触顶会暂停保留已采数据、可继续采集。导出前建议用行数与页面声明核对一遍。

**Q：翻页采集中途停了，提示「未能确认已进入下一页」？**

A：这句话说的不是"页面坏了"，而是"扩展点了页码，却拿不出证据说明确实换到了下一页"。最常见形态是点击后表格先被清空或换成加载骨架，随后又变回原来那一页；也有站点页码数字压根没动。此时采集停在当前页、**已采数据全部保留**：先在页面上核对现在是第几页，点「继续」就从这一页续采；若页面确实一直停在同一页，说明这个入口不可靠，改用「手动选择」点真正的下一页按钮或页码数字。扩展不会因为看不清落点就把同一页重复采一遍，也不会把它当成"已采完"悄悄收场。

还有一种形态单独提示：如果**页码确实动了、表格内容却一动不动**，暂停文案会直接写明"当前翻页入口可能与表格不联动"。这类站点的分页器和表格是两套东西（常见于会话过期后接口静默失败），点它只是在挪高亮。扩展此时不会继续往下采，请按提示到「配置列 → 翻页采集 → 手动选择 → 去页面选择」重新点一个真正联动的入口。

**Q：采集完成后页面自己跳走了，采到的数据还能拿到吗？**

A：能。打开可运行面板的网页，在「保留的采集任务」中点「恢复结果」查看或导出；原网页可已关闭，浏览器重启后也可恢复。已确认开始的任务重复输出不再扣费，升级前旧任务按原协议核对。继续采集需回原绑定标签核对同一张表与实际落页；标签身份已变化时先输出结果，再新建任务采后续页。不要为恢复而卸载扩展或清空本地任务。

**Q：模板保存后下次打开没匹配到？**

A：确认模板的匹配维度设置是否正确。按域名匹配只比对 hostname 部分（不含路径和参数），按完整 URL 需要完全一致。

**Q：模板存储空间不足？**

A：进入模板管理页清理不再需要的模板。`chrome.storage.sync` 总容量上限为 100KB，每个模板数 KB 不等。

**Q：自定义规则保存后在哪里使用？**

A：回到列配置界面，在目标列勾选「识别」并打开规则选择器，自定义规则在选择器内单独成区；选定后像内置规则一样挂到该列。

**Q：删除自定义规则会影响已有模板吗？**

A：会。如果模板中有使用该自定义规则的识别列，删除规则后应用模板时会提示「该模板包含已删除的规则」，对应识别列将被跳过。

**Q：如何验证自定义正则是否正确？**

A：在新增/编辑规则时，使用正则测试框输入示例字符串即可实时验证。匹配成功显示「✅ 匹配」，语法错误会显示红色提示。

**Q：免费版翻页次数用完了怎么办？**

A：按账户实际可用次数使用，不保证固定赠送数量或成功完成固定次数。新免费采集确认开始扣1次，开始后不退；同任务继续、切换和重复输出不再扣。用完后可联系开发者由管理员后台补充额度，到账后刷新余额，或购买 Pro。赠额按钮只复核原未到账机会。采集与网页填充翻页共享余额，填充仍按批次开始扣费；卸载重装不补发，恢复原账本需有效访问令牌或强恢复凭据，指纹与账号哈希不能代替。

**Q：Excel 填充网页要 Pro 吗？**

A：**单页批量填写免费**，不激活也能用；填充翻页开始时消耗上面那份免费额度（与采集共享，手动或自动翻页采用同一填充记账规则）。网页填充模板（保存范围、映射与定位）是 Pro 功能：免费用户在成功填完一行后会看到一条带锁的升级说明，填充前不显示，点顶部「管理」也会像采集模式一样提示升级。

**Q：如何订阅 Pro？**

A：点击浮动面板「升级 Pro」或「Pro」，再选新页面顶部「订阅」：微信/支付宝扫码付款（月费 <Fact product="table-flow" id="pricing.pro.monthly" /> / 年付 <Fact product="table-flow" id="pricing.pro.yearly" />）→ 添加开发者 QQ 好友，发送付款截图与设备码（备注「TableFlow 订阅」）→ 获取激活码后在订阅页输入激活。

**Q：激活码可以换设备使用吗？**

A：一码一设备。激活码在线绑定时与设备绑定；需要换设备时，在旧设备的「账户」页点击「解绑设备」，解绑后激活码可在新设备重新激活。

**Q：激活 Pro 需要联网吗？**

A：常规激活（hybrid）：激活码本地验签通过即可解锁（可离线使用）；激活/解绑时需联网完成在线绑定。网络不可达时先临时解锁，联网后后台自动确认。完全断网环境可购买离线 Pro，建议先在可联网环境试用并确认目标网页可用。办理「离线激活」时：先在订阅页选择该模式，再复制「离线申请码」向开发者申请离线授权文件，本地验签即激活。在线设备码与离线申请码不能互换，复制前请核对当前激活模式。离线授权文件到期后本机转为免费用户，免费翻页需要联网（详见[免费版与 Pro](/table-flow/pricing)）。

**Q：为什么我的模板/识别列/高级去重不可用？**

A：这些是 Pro 功能，免费版锁定。订阅并激活后自动解锁。（Excel 填充网页的单页批量填写本身免费，锁住的只是它的填充模板。）

**Q：Canvas 画出来的表格能采吗？**

A：不能。canvas 表格本质是一张图片，读不出里面的文字，这类页面明确不支持。

**Q：数据还没加载到页面上（只在接口里）能采吗？**

A：不能。TableFlow 读的是浏览器渲染出来的成品页面，页面没画出来的行就采不到。

**Q：悬浮图标不见了，或者面板关掉后找不回来？**

A：两种情况分开处理。**图标被隐藏了**（之前点过图标右上角的「×」）：点一下浏览器工具栏的 TableFlow 扩展图标，图标会恢复并直接打开面板；刷新页面也会恢复。**图标还在、只是面板收起了**：点扩展图标只会重扫一次页面，不会替你打开面板——面板的开合始终由屏幕上的悬浮图标负责，点它即可重新展开。

**Q：设置项太多，忘了某个开关在哪个模块？**

A：用独立管理页顶部的搜索框（窄窗口可能换行）：输入关键词（如「隐藏图标」「导出格式」「iframe」）即出结果，也支持英文；点中结果会自动切到对应模块、滚到那一项并短暂高亮。空输入时还能看到「常用搜索」和你的搜索历史，`⌘K` / `Ctrl+K` 可随时聚焦搜索框。搜索只覆盖设置页自己的控件，面板内按钮与导出步骤里的选项搜不到。

**Q：会不会把我的数据上传？**

A：采集、预览、导出都在本地完成。身份准备/恢复、在线激活、免费额度记账与独立更新检查可能联网；网页填写的字段会由目标网站处理。最小错误诊断保存在本地内存；扩展请求的域名、方法、状态与耗时概览另保存在本次浏览器会话存储中，均不自动上传，可在调试控制台主动导出。详见[隐私政策](/table-flow/privacy)。

## Chrome 信任提示

**Q：商店安装后为什么显示「增强型安全浏览功能不信任此扩展程序」？**

A：这是 Chrome 增强型安全浏览的扩展信任判断，与商店审核是否通过分开。Google 未公开针对 TableFlow 的具体评估原因；仅凭一次更新后出现提示，无法确定是哪个版本或权限变更造成。开发者没有 manifest 开关可以设为受信任，更新文档或重新提交版本也不保证消除提示。请核对[官方商店来源](/table-flow/install)，查看权限和[隐私政策](/table-flow/privacy)，按浏览器提示决定是否继续使用。参考 [Chrome 官方说明](https://support.google.com/chrome?p=cws_enhanced_safe_browsing)。

**Q：翻页失败会一直重试吗？**

A：下一页按钮与页码序列采集的重试次数默认是 5，可在「设置 → 表格采集 → 翻页与等待」设为 0–20；0 表示关闭此策略。单阶段最长 60 秒，耗尽后保留已采数据并暂停。当前页、加载更多、无限滚动和虚拟封页采用各自的策略，详见[使用指南](/table-flow/usage-guide#翻页异常自动重试)。

## 手动翻页与设置

**Q：没页码的虚拟表或有重复记录的相邻页可用吗？**

A：无页标必须有唯一关联分页动作及旧页未出现的新记录；有真实页码或稳定页键时可保留相邻页共享业务记录。仅旧记录重现、排序或节点重建不能证明换页。列结构变化/回退时会暂停并保留确认数据。

**Q：旧教程找不到数据设置或等待设置？**

A：新版按九类组织；采集延迟与翻页等待上限在「表格采集 → 翻页与等待」，列表识别在「表格采集 → 识别范围」，列名规则在「模板与规则 → 列名规则」。统计指标与完整性检测在「统计分析」设置。

**Q：在线取码、采集或停止/恢复提示联网请求超时，能调整等待时间吗？**

A：在「设置 → 表格采集 → 翻页与等待」的「联网确认」分区调整「联网请求超时」，默认 15 秒，可设 1–120 整数秒，下一次请求生效。网络慢时可调高后重试原操作；原待确认请求和已完成数据会保留，恢复同一任务不会换号重扣。该设置也覆盖运行续租、执行确认和停止状态核验，与网页加载等待、激活码验签期限独立。在线设备码获取超时可按同样路径调整；离线申请码可切换「离线激活」在本机取得。网络断开、服务拒绝或归属变更需按各自提示处理。

## 购买与续费

**Q：在线购买和续费从哪里开始？**

A：面板点「升级 Pro / Pro」→ 顶部「订阅」，使用已有微信 / 支付宝收款码付款，把付款截图和在线设备码发给开发者，收到激活码后粘贴激活。续费联系开发者，由管理员后台办理，再到「账户」核对有效期；前台不另建套餐、凭证上传或原码续费申请。完整步骤见[购买与续费](/table-flow/pricing#在线购买)。

**Q：赠额按钮能在次数用完后无限申请吗？**

A：不能。「申请赠额」只复核原本尚未到账的赠额机会，没有可复核机会时显示实际状态。需要额外额度或续费联系开发者，管理员可以在后台直接调整；不承诺固定赠送次数。

**Q：Debug 会默认修改网页计时器吗？**

A：不会。只有在调试控制台「…」菜单点「解除 debugger」并手动确认后，才对当前 frame 的未来新增纯 debugger 计时回调启用安全步骤。普通业务计时器、混合业务函数和字符串，以及无法安全识别的回调保持原样，仍可能触发 debugger。破坏性清扫需要另行明确选择；旧页面中的旧补丁需刷新网页移除，关闭控制台不能撤销。见[排查手册](/table-flow/troubleshoot#解除-debugger-与页面计时器)。
