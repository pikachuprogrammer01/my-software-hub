# 常见问题

> 来源：`table-flow/docs/USAGE_GUIDE.md` 常见问题（原文摘录）。

**Q：表格没有被识别出来？**
A：点击「刷新」按钮重新扫描。确认表格不是通过 JavaScript 延迟渲染的（等待页面加载完成后再试）。某些复杂框架表格可能需要等待框架组件完全渲染。页面是 `ul/li` 列表的话，确认设置页「数据设置 → 列表识别（ul/li）」已开启；仍不出现时可把「列表识别严格度」放宽到「宽松」再重扫（默认「标准」与历史行为一致）。

**Q：列表采集出来了，但列名是「列1」「列2」？**
A：说明这个列表既没有页面自己的列名声明，也没有命中内置规则。到设置页「数据设置 → 列名规则」加一条：点「+ 新增规则」，在「我要识别什么？」里选「日期」「标题链接」这类现成选项（选完条件就自动填好了），填一个列名保存即可，重扫后按你的名字显示。

**Q：导出的手机号变成科学计数法了？**
A：使用 Excel (.xlsx) 格式导出会自动处理此问题。如果使用 CSV 格式，在 Excel 中打开后请将单元格格式设为「文本」再粘贴。

**Q：翻页采集没有自动翻页？**
A：尝试手动选择翻页入口：在点击「翻页模式」开关后点击「手动选择」，然后点击页面上的下一页按钮或页码数字。框架类网站可能需要手动选择。

**Q：表格只采到看得见的那几行（虚拟列表）？**
A：卡片带「虚拟列表」徽标的表，采集时会自动滚动逐屏补回未渲染的行，**这一步不需要开启自动翻页**。没有徽标却只采到几行，说明该页面的虚拟形态还没被判定命中（常见于尚未适配的组件库），此时只会拿到页面上已渲染的行且不报缺行——请与页面行数核对后展开或重新扫描。

**Q：页面底部是「加载更多」，能一次点到底吗？**
A：能。入口会被自动识别（也可在「手动选择」里点选它），采集按「新增行数」推进：每点一轮只把新长出来的行计入，旧行不会重复；按钮消失/禁用、或连续 2 轮点击都没有新行时按数据末尾自动停止，终止原因会写进采集结果提示。采集轮数与翻页页数相互独立，默认单次最多 200 轮，触顶会暂停保留已采数据、可继续采集。导出前建议用行数与页面声明核对一遍。

**Q：翻页采集中途停了，提示「未能确认已进入下一页」？**
A：这句话说的不是"页面坏了"，而是"扩展点了页码，却拿不出证据说明确实换到了下一页"。最常见形态是点击后表格先被清空或换成加载骨架，随后又变回原来那一页；也有站点页码数字压根没动。此时采集停在当前页、**已采数据全部保留**：先在页面上核对现在是第几页，点「继续」就从这一页续采；若页面确实一直停在同一页，说明这个入口不可靠，改用「手动选择」点真正的下一页按钮或页码数字。扩展不会因为看不清落点就把同一页重复采一遍，也不会把它当成"已采完"悄悄收场。

还有一种形态单独提示：如果**页码确实动了、表格内容却一动不动**，暂停文案会直接写明"当前翻页入口可能与表格不联动"。这类站点的分页器和表格是两套东西（常见于会话过期后接口静默失败），点它只是在挪高亮。扩展此时不会继续往下采，请按提示到「采集配置 → 手动选择」重新点一个真正联动的入口。

**Q：采集完成后页面自己跳走了，采到的数据还能拿到吗？**
A：能。有些站点在采集结束后把整页导航到登录页或会话超时页，面板内存里的数据会随之清空，但结果快照仍写在本地缓存里。回到**同一个标签页**重新打开该站点，顶部会出现「上次采集已完成（N 条）· 页面刷新或跳转后数据已保留，可直接导出」，点「直接导出」即可。缓存按标签页存放，换标签页就找不回来了；这类快照只能导出或丢弃，不会被当成未完成任务继续采集。

**Q：模板保存后下次打开没匹配到？**
A：确认模板的匹配维度设置是否正确。按域名匹配只比对 hostname 部分（不含路径和参数），按完整 URL 需要完全一致。

**Q：模板存储空间不足？**
A：进入模板管理页清理不再需要的模板。`chrome.storage.sync` 总容量上限为 100KB，每个模板数 KB 不等。

**Q：自定义规则保存后在哪里使用？**
A：回到列配置界面，在目标列勾选「识别」并打开规则选择器，自定义规则在选择器内单独成区；选定后像内置规则一样挂到该列。

**Q：删除自定义规则会影响已有模板吗？**
A：会。如果模板中有使用该自定义规则的识别列，删除规则后应用模板时会提示「该模板包含已删除的规则」，对应识别列将被跳过。

**Q：如何验证自定义正则是否正确？**
A：在新增/编辑规则时，使用正则测试框输入示例字符串即可实时验证。匹配成功显示「✅ 匹配」，语法错误会显示红色提示。

**Q：免费版翻页次数用完了怎么办？**
A：免费版自动翻页默认授予 <Fact product="table-flow" id="limits.freePaging.flows" /> 次采集流程（页数不限，中断/刷新同样消耗次数），实际余额以平台为准。用完后翻页会锁定并提示升级；额度耗尽后扩展会在预算允许时向平台核对余额，**平台重置或追加授予后会自动恢复**，卸载重装并不能刷出新额度。Excel 填充网页的自动翻页与采集共用这一份额度。订阅 Pro 可解锁无限翻页。

**Q：Excel 填充网页要 Pro 吗？**
A：**单页批量填写免费**，不激活也能用；只有在填充过程中开启自动翻页时才消耗上面那份免费额度（与采集共享）。网页填充模板（保存范围、映射与定位）是 Pro 功能：免费用户在成功填完一行后会看到一条带锁的升级说明，填充前不显示，点顶部「管理」也会像采集模式一样提示升级。

**Q：如何订阅 Pro？**
A：点击工具栏「Pro」按钮进入订阅页：微信/支付宝扫码付款（月费 <Fact product="table-flow" id="pricing.pro.monthly" /> / 年付 <Fact product="table-flow" id="pricing.pro.yearly" />）→ 添加开发者 QQ 好友，发送付款截图与设备码（备注「TableFlow 订阅」）→ 获取激活码后在订阅页输入激活。

**Q：激活码可以换设备使用吗？**
A：一码一设备。激活码在线绑定时与设备绑定；需要换设备时，在旧设备的「账户」页点击「解绑设备」，解绑后激活码可在新设备重新激活。

**Q：激活 Pro 需要联网吗？**
A：常规激活（hybrid）：激活码本地验签通过即可解锁（可离线使用）；激活/解绑时需联网完成在线绑定。网络不可达时先临时解锁，联网后后台自动确认。完全断网环境可改用「离线激活」：凭设备码向开发者申请离线授权文件，本地验签即激活。无论哪种激活方式，订阅页顶部都常驻展示本设备码。离线授权文件到期后本机转为免费用户，免费翻页需要联网（详见[免费版与 Pro](/table-flow/pricing)）。

**Q：为什么我的模板/识别列/高级去重不可用？**
A：这些是 Pro 功能，免费版锁定。订阅并激活后自动解锁。（Excel 填充网页的单页批量填写本身免费，锁住的只是它的填充模板。）

**Q：Canvas 画出来的表格能采吗？**
A：不能。canvas 表格本质是一张图片，读不出里面的文字，这类页面明确不支持。

**Q：数据还没加载到页面上（只在接口里）能采吗？**
A：不能。TableFlow 读的是浏览器渲染出来的成品页面，页面没画出来的行就采不到。

**Q：会不会把我的数据上传？**
A：采集、预览、导出都在本地完成。Pro 激活与免费额度记账需要联网；运行诊断只保存在本地内存中，需要时可在调试控制台手动导出。详见[隐私政策](/table-flow/privacy)。
