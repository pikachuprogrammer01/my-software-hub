# 免费版与 Pro

> 来源：`table-flow/docs/USAGE_GUIDE.md` Pro 订阅 + `docs/SCOPE_AND_FEATURES.md` §4.5/§七。
> 已按要求删去授权机制的实现细节（签名算法、本地快照加密方式、时钟容差等）——这些属于防破解信息，不对外发布；站点只陈述用户可感知的事实。

## 模式

TableFlow 采用**订阅制**：核心采集与导出功能免费，Pro 功能通过激活码解锁。

## 价格与购买

- **月付 <Fact product="table-flow" id="pricing.pro.monthly" /> / 年付 <Fact product="table-flow" id="pricing.pro.yearly" />**
- 支付渠道：微信 / 支付宝（各含月费、年费两张收款码，均在订阅页内展示）

**三步**：

1. **付款**：点工具栏「Pro」按钮进入订阅页 → 选微信或支付宝 → 扫码支付
2. **获取激活码**：添加开发者 QQ 好友，发送付款截图 + 订阅页顶部的**设备码**（备注填「TableFlow 订阅」便于核对）
3. **激活**：在订阅页粘贴激活码（`TF-` 开头）确认；激活成功立即解锁，「账户」页显示许可证状态

## 激活须知

- **一码一设备**。换设备时先在旧设备「账户」页点「解绑设备」，解绑后激活码可在新设备重新激活（解绑需联网，有频率限制）。
- **常规激活（hybrid）**：激活码本地验签通过即解锁，激活后可离线使用；激活/解绑这一步需联网完成绑定。网络不可达时先临时解锁，联网后后台自动确认；确认失败（如该码已绑其他设备）会自动撤回。
- **免费版自动翻页需联网**：免费额度由服务端按设备记账，完全断网且未持有 Pro/离线授权时，翻页流程会被明确拒绝并提示联网或升级——不会静默失败。默认 <Fact product="table-flow" id="limits.freePaging.flows" /> 是平台授予量，实际余额以平台为准：额度耗尽后扩展仍会（在有预算的前提下）向平台核对余额，**平台重置或追加授予后会自动恢复**，无需重装；卸载重装也不会刷出新额度。Excel 填充网页的自动翻页与这里共用同一份额度。

## 离线激活（完全断网环境，Pro 专属）

1. 在目标设备打开订阅页，顶部常驻「本设备码」卡片（前 16 位短码可一键复制；完整 64 位设备码需在该页开发者工具 Console 中查看复制）
2. 把「激活码 + 完整设备码」提供给开发者，由平台签发**离线授权文件**（`TFOL-` 开头，与本机设备码强绑定，有效期不超过激活码有效期）
3. 订阅页「离线激活」粘贴文件（新版文件已内嵌激活码）→ 点激活；**授权有效期内全程零网络请求**
4. 注意：离线授权**不经服务器登记**，平台撤销后纯离线设备不会感知；换设备或需提前吊销请联系开发者重新签发
5. **文件到期后本机转为免费用户**：免费翻页额度改走服务端的免费通道，与首次安装的免费用户完全一样需要联网（设备注册 → 读服务端余额 → 扣减）。完全断网的环境只能续期或申请新的离线授权文件

## 账户页

展示许可证状态、过期倒计时、免费/Pro 功能对比表，以及「解绑设备」入口。离线授权的解绑只清除本机状态，激活码本身不换绑。

## 隐私

采集、预览、导出全部在本地完成；只有 Pro 激活与免费额度记账需要联网；运行诊断只保存在本地内存中，需要时由用户在调试控制台手动导出。完整说明见[隐私政策](/table-flow/privacy)。
