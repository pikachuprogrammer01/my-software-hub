# 功能清单

当前版本的入口只有一个：**批量导入通讯录**三步向导（数据源 → 列映射 → 预览与导出）。下面按这三步列出实际能做什么。

## 1. 读取数据源

| 项目 | 支持情况 |
|---|---|
| Excel | `.xlsx` `.xlsm` `.xltx` `.xltm` `.xls` |
| CSV | 支持；编码自动识别，依次尝试 BOM → UTF-8 → GBK → UTF-16 |
| 文本 | `.txt` **只能作为导出格式，不能作为输入** |
| 取样 | 列映射界面按前若干行样本推断列名 |

## 2. 列映射与模板

- 把文件里的任意列拖到「姓名 / 手机号 / 公司 / 职位 / 邮箱 / 备注」等目标字段上。
- 映射关系可以存成**模板**：新建、从表头一键批量新建、重命名、删除、套用、拖拽排序；改动未保存时会在套用时询问。
- 同一批名单反复导出时，套模板可以省掉每次重新对列。

## 3. 号码清洗

| 规则 | 行为 |
|---|---|
| 中国大陆手机号校验 | 11 位、以 `1` 开头、第二位合法；`+` 开头的号码按国际格式放行 |
| 非法号码 | 预览里标红，方便一眼看到脏数据 |
| 一格多号 | 按 `, ， ; ； 、`、换行、`\|` 拆成多条 |
| 来源声明行 | 自动跳过企查查 / 天眼查 / 爱企查 / 启信宝 / 水滴信用的声明与免责行 |
| 数据被截断 | 弹出告警而不是静默少导出 |

## 4. 预览

预览最多显示 <Fact product="wps-enhancer" id="limits.previewRows" suffix=" 行" />，用于确认清洗结果，不是导出上限；导出走完整数据。

## 5. 导出

| 格式 | 说明 |
|---|---|
| `.vcf` | vCard 3.0，写入 `FN`、`TEL;TYPE=CELL`、`ORG`、`URL`，按规范做 75 字节折行；iPhone 与安卓通讯录可直接导入 |
| `.xlsx` | 清洗后的干净表格；**同名合并只在这个格式下可用** |
| `.csv` | 同上，纯文本 |
| `.txt` | 纯文本清单 |

- 姓名可加前缀 / 后缀 / 时间戳，各字段可单独勾选是否写出。
- 导出完成后应用内给出**通讯录导入指南**（iPhone、安卓、批量三种路径）。
- 不输出 `.xls`（旧格式）。

## 6. 设置与日志

设置分 6 个页签：导入处理、导出格式、内置列、日志、更新、关于。

- 日志页签显示最近 200 行运行日志，出问题时能直接看到是哪一步、哪个文件。
- ⌘, （Windows 为 Ctrl+,）打开设置。
- 「关于」里写明所有文件均在本机处理。

## 7. 卸载

应用内置卸载向导，会清掉应用本体与程序文件；**用户数据（模板、设置）默认不勾选删除**，需要自己确认。
