# 如何更新

## 检查时机

- 应用启动后约 3 秒向更新清单发一次请求，**只在启动时检查一次**，运行期间不会定时轮询。
- 发现新版本时右下角给出通知，提示去「设置 → 更新」查看。
- 想主动确认，打开 **设置 → 更新 → 检查更新**。

更新清单地址默认指向 Gitee 发布仓，可在设置里改；网络走系统代理设置。

## 更新步骤

内置更新器**不会自动安装**。它的流程是：检查 → 下载压缩包到「下载」目录 → 校验完整性 → 给出替换指引。你要做的是：

1. **完全退出**正在运行的 WPS 增强工具（⌘Q，不是只关窗口）。运行中替换会把旧进程留在内存里，看起来像"更新没生效"。
2. 按应用内提示打开下载目录，解压。
3. 把新的 `wps-enhancer-go.app` 拖回「应用程序」，覆盖旧的。
4. 重新打开。首次覆盖后仍可能弹一次安全提示，处理方式见[安装与首次打开](/wps-enhancer/install)。

## 为什么更新页没有下载按钮

应用内更新器负责已安装用户的升级，避免用户拿站点包覆盖应用刚下载好的更新包。首次安装或应用内更新网络不通时，请到[安装页](/wps-enhancer/install)按平台选择 Gitee 或 GitHub 的 ZIP 下载按钮。

## Intel Mac 用户

当前发版只产出 Apple Silicon（arm64）包，更新清单里没有 `macos-x86_64` 条目，因此 Intel Mac 上检查更新会得到"缺少对应平台的下载地址"。这是发布链路的缺口，不是你的网络问题；在补上之前，Intel 机器请沿用已装版本。
