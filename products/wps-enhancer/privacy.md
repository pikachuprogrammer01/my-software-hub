# 隐私说明

## 你的表格不会离开本机

读取的客户名单、列映射、清洗结果、导出的 vCard / Excel / CSV / TXT——全部在本机内存与磁盘上完成。**没有任何一条代码路径会把文件内容上传或发给服务端**。应用内「关于」页写的也是同一句话。

## 它什么时候联网

只有三类请求，且都是主动行为：

| 场景 | 目标 | 会不会发生 |
|---|---|---|
| 检查更新 | 更新清单地址（默认 Gitee 发布仓） | 每次启动一次；可在设置里关掉自动检查 |
| 下载更新包 | 清单里给出的压缩包地址 | 只在你在设置里点了下载之后 |
| 授权校验 | 授权服务地址 | **当前版本界面没有激活入口，正常使用时不会触发** |

检查更新用的请求标识是更新器自己的 User-Agent，不携带你的文件名、表格内容或任何身份信息。

没有埋点、没有统计 SDK、没有崩溃上报。

## 数据存在哪里

| 平台 | 目录 |
|---|---|
| macOS | `~/Library/Application Support/WPSEnhancer` |
| Windows | `%LOCALAPPDATA%\WPSEnhancer` |

里面是设置与列映射模板。运行日志也在本机，可在「设置 → 日志」里查看最近内容。

**卸载不会自动删除这个目录**——除非你在卸载向导里明确勾选。想彻底清掉自己的痕迹，卸载后手动删除该目录。

## 需要你自己判断的边界

- 这个包未做 Apple 公证、Windows 侧无代码签名，安全软件给出警告属于预期行为，处理方式见[安装与首次打开](/wps-enhancer/install)。
- 通讯录是敏感数据。导出后的 `.vcf` 文件归你管，请别留在共享盘或聊天工具的下载目录里。

本页描述的是当前发行版本的行为，核对日期 2026-10-05。
