# 它解决什么

销售、行政、运营常遇到同一件事：客户名单是一张手工维护的表，手机号一格塞三个号码、有的带 `+86`、有的带空格和横杠，而手机通讯录只认干净的号码。复制粘贴到几千行时一定会出错。

WPS Enhancer 做的是一件很窄的事：**把这张表变成能导入手机的通讯录文件**。

## 当前版本只有一个功能

已上线的是「批量导入通讯录」三步向导：选数据源 → 映射列 → 预览并导出。

主界面上的 Word 标签目前是占位入口，点进去会明确提示「功能待加入」。**没做的功能我们不会写在页面上**，这一页的功能清单与代码里的实际入口一一对应。

## 处理链路

```text
Excel / CSV 客户表 → 读取工作表 → 列映射与模板 → 号码清洗与校验 → 预览 → vCard / Excel / CSV / TXT
```

导出物里的 `.vcf` 是 vCard 3.0 格式，iPhone 与安卓通讯录都能直接导入。

## 与 WPS Office 的关系

WPS Enhancer 是独立的第三方桌面程序，**不是金山办公的组件，也不嵌入 WPS 进程**。它只读写表格文件，因此不要求你登录 WPS，也不需要 WPS 处于运行状态。

## 适合与不适合

| 适合 | 不适合 |
|---|---|
| 几百到几千行的客户名单整理成通讯录 | 需要复杂表格计算、透视、图表 |
| 手机号格式混乱、需要批量校验与拆分 | 通用 Excel 编辑器（那是 WPS / Excel 本身的事） |
| 同一份名单要反复导出给不同设备 | 需要云端协作与多人同时编辑的场景 |
