# 常见问题

**Q：按了开始，但什么都没被点到。**
A：两个原因占九成。一是**辅助功能权限**没生效——面板上应显示「权限已开启」，否则点「前往系统设置」补上；二是**目标应用不在前台**，点击事件发给的是当前接收事件的窗口。先确认权限状态，再切到目标窗口试。

**Q：快捷键按了没反应。**
A：注册失败时应用会**自动恢复成原来可用的组合键**并给出提示，所以"没反应"通常意味着你按的那个组合键被系统或别的应用抢走了。换一个包含 ⌘ 或 ⌃ 的组合再试（⌘Q、⌘W 这类系统级组合不允许使用）。

**Q：刚覆盖安装了新版本，突然不能点了。**
A：正常现象。替换 `.app` 会让原来的辅助功能授权失效，去 **系统设置 → 隐私与安全性 → 辅助功能** 里把 Auto Clicker 关掉再打开；列表里出现两条重复项时，删掉旧的只留一条。

**Q：「长按」和「单击」有什么区别？**
A：单击是按下与抬起成对立即发出；长按会按住你设定时长再抬起，并且**抬起前重新读取鼠标位置**，所以拖动过程中你移动了鼠标，抬起点也会跟着走。

**Q：它会不会点错地方？**
A：它每次都点鼠标当前所在位置。这意味着运行期间你手动移动鼠标，点击目标就跟着变了——这是设计，不是 bug，但也别一边让它连点一边用鼠标干别的。

**Q：收费吗？要注册吗？**
A：免费，MIT 开源。没有账号、没有激活码、没有试用到期。

**Q：我的点击记录会被上传吗？**
A：不会。这个应用**没有网络层**，运行期间的点击计数只在界面上显示，退出即消失；只有设置项存在本机。

**Q：有 Windows 版吗？**
A：没有，只有 macOS 版。

**Q：能用脚本或命令行控制它吗？**
A：不能。它只有界面与全局快捷键，没有 URL scheme、没有命令行参数、也没有 AppleScript 字典。需要脚本化自动化的话，这个工具不适合。

**Q：为什么不显示版本号？**
A：应用窗口本身不显示版本，这是已知的设计缺口。要知道自己装的是哪一版，看下载文件名；本页上方的按钮会标明当前核对的版本。
