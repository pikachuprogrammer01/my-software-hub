# 它解决什么

有些操作就是得重复点几百次：批量确认、逐条翻页、把列表里的每一项点开一遍。Auto Clicker 只解决这一件事——**在鼠标当前位置，按你设定的间隔，持续发送鼠标事件**。

## 三条设计取向

- **跟随鼠标，不记坐标。** 每一次点击前都重新读取鼠标当前位置，你可以一边让它点、一边把鼠标挪到下一个目标上。不需要填 X/Y，也不需要框选区域。
- **常驻菜单栏，不占 Dock。** 启停都在菜单栏里，随时能停。
- **不联网、无账号、无激活。** 整个应用没有任何网络层，设置只存在本机。

## 适合

| 适合 | 不适合 |
|---|---|
| 同一个位置或连续位置的高频点击 | 需要精确点到固定坐标的自动化 |
| 手动引导的批量操作（你负责移动鼠标） | 多步骤流程录制与回放 |
| 长按拖拽、按住不放这类按住语义 | 键盘宏、快捷键脚本 |
| 一次性任务，用完就停 | 定时任务、按计划启动 |

## 与"脚本类"工具的差别

AppleScript、键盘鼠标录制器那类工具解决的是"把一串动作录下来重复执行"。这个应用刻意不做那件事：它只发鼠标点击，因此也不需要理解界面结构，界面上东西挪了它照样能跟着点。
