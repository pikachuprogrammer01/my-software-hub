# 功能与边界

## 可配置项

| 项目 | 可选值 |
|---|---|
| 鼠标键 | 左键 / 右键 |
| 点击方式 | 单击 / 长按 |
| 次数模式 | 无限 / 指定次数 |
| 点击间隔 | <Fact product="auto-clicker-mac" id="limits.intervalMin" prefix="从 " /> 到 <Fact product="auto-clicker-mac" id="limits.intervalMax" suffix=" 毫秒" /> |
| 长按时长 | 同上范围 |
| 全局快捷键 | 自定义录制 |

间隔与长按时长的输入框只接受数字，非数字字符会被直接过滤；超出范围会给出提示而不是静默改成别的值。

默认值：左键、单击、无限次、间隔 100 毫秒、指定次数 1000、长按 500 毫秒。

## 跟随鼠标的真实行为

- **每次发送事件前重新读取鼠标位置**，所以运行中你可以把指针移到下一个目标上，它跟着走。
- 单击的按下与抬起在同一次临界区里成对发出，不会被别的进程插进来。
- 长按在**抬起前再读一次位置**——这样 `mouseUp` 不会落在几秒前按下时的旧坐标上。这一条是拖拽类操作能不能用的关键。

## 全局快捷键

- 出厂默认是 **⌥C**。
- 必须包含 ⌘、⌥、⌃ 中至少一个修饰键；⌘Q、⌘W 这类系统级组合会被拒绝，避免连点器把"退出应用"当成启动键。
- 改键方式：点录制框 → 直接按下组合键；按 Esc 取消。
- 如果新组合键已被系统或其他应用占用，注册会失败，此时**自动恢复成原来可用的键**并提示原因，不会留下一个按了没反应的配置。

## 运行中能看到什么

面板显示已完成点击数、当前鼠标键与点击方式、生效中的快捷键，以及权限状态。没有速率、预计剩余时间、历史记录这类东西——它只回答"点了几下、还在不在点"。

## 权限与状态

- 需要**辅助功能**权限。未授权时开始按钮是禁用的，面板上给出「前往系统设置」的入口。
- 权限状态每秒刷新一次，你在系统设置里打开开关后回到面板，不用重启应用。

## 菜单栏

常驻菜单栏图标，包含开始 / 停止、打开面板、退出。面板右上角的电源按钮会先停任务再退出。

## 明确不做

固定坐标点击、多点位序列、按显示器分别设定、键盘宏、录制回放、定时任务。这些都在设计时排除掉了：一旦引入坐标，"跟随鼠标"这个最简单的心智模型就没了。
