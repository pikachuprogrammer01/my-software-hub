## 当前文案

> 从网页表格中扫描、预览、整理并导出结构化数据；也支持把本地 Excel 按用户配置填入网页。表格与工作簿在浏览器本地处理，不上传原始工作簿或采集表格到开发者服务器。最小运行诊断仅在扩展本地内存记录，可由用户主动导出；扩展没有远程错误上报通道。

网页填写和获准的保存动作会把字段交给目标网站，网站可能自行校验、保存或联网；不能把“不上传原文件”写成“填入的字段不会离开浏览器”。

## 数据实践

- 设备注册和风险观察向自有授权服务器发送六项设备特征、可选账号标识 SHA-256 哈希；原始账号 id / 邮箱不上传、不落盘、不进日志。账号哈希与指纹仅作风险观察，不能恢复或合并旧账本。
- 免费额度使用服务端设备身份、访问令牌、强恢复凭据、操作与请求标识进行记账和核对。授权服务器在自己域下设置 Secure/HttpOnly 强恢复 Cookie，由浏览器携带；扩展没有 cookies 权限，不读取第三方网站 Cookie。
- 后台扩展请求只记录域名、方法、状态与耗时等概览，保存在浏览器会话存储，可跨后台重启恢复；默认存在，不由调试控制台开关关闭，也不自动上传。
- 不使用第三方错误上报 / 遥测服务。没有“发送匿名诊断”开关，不能把旧 Sentry 文案复制到当前申报。
- 如后台询问是否处理网页内容或个人 / 健康 / 财务信息，应按实际可读取、填写和本地处理范围如实申报；不能因“不上传开发者服务器”一律填写“不处理”。身份凭据需区分自有授权服务与目标网站密码 / Cookie。
- 不出售数据，不用于广告、画像或跨站跟踪。留存、用户控制与具体字段以当前隐私政策和设备特征披露为准。

## 提交检查

1. 对照最终 manifest 核对 storage、scripting、activeTab、tabs、identity、identity.email 与主机权限理由；不按旧版本猜权限。
2. 同步商店详细描述、数据实践勾选项、隐私政策和独立设备披露；保存提交证据与日期。
